# G1 可选 hybrid 的执行裁定（先于运行）

日期：2026-09-22。G1 的 16 个物理 pair 在终点的自由反馈 finite-pair gain 均为负，但 teacher-action 路径并不一致；两种路径既改变动作，也改变随后的模型输入。只比较两条误差曲线无法判断哪一段贡献了自由反馈的相对效应失真，这直接影响后续应检验共享处理器还是反馈动作机制。因此执行计划允许的最小同动作 hybrid：对每条已保存的真实 C 向量，在 depth 1–4 用模型预测动作查询一次冻结模型，最多 17×4=68 次 transition。首步动作相同，不重复查询。

它只把自由反馈下一步误差拆为「不同输入、相同反馈动作」＋「相同真实输入、不同动作」＋「真实输入和真实动作上的模型残差」；分配依赖此加减顺序，不是唯一因果归因。真实未来向量与实际动作仅为评价参照，绝不进入更新、候选生成或新环境交互。判据为代数闭合、与 G1 向量身份一致、实测 68 次 batch-1 predictor 调用、模型参数不变；不据此宣布 P 的有效性。
