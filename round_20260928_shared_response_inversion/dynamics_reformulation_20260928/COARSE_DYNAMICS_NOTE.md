# 从粗粒化到响应保持的受控实现：候选数学对象与判决边界

2026-09-28。独立形成笔记；未使用本地 skills，未修改原生代码，未训练模型、调用环境或运行新的视觉实验。读取旧报告并核查原始文献；本文的两个小例子使用 Python Fraction 实际复算。

## 裁定

这一族问题中，最值得保留的表述是：**寻找一个能够在动作作用下递推、并保留相关未来输出的受控实现。** 待求对象是状态坐标及其转移，而非预先固定原生预测再求一个在线修正量。Mori–Zwanzig 说明粗粒化后为何可能需要记忆；预测状态说明何谓充分状态；平衡截断说明为什么状态的重要性不能只由视觉方差或重建误差决定。

其中，对本任务最有针对性的计算原则是**输入到未来输出的响应保持**。但经典理论和神经降阶近邻已覆盖大量基础内容，目前只能给它“建模优先”，不能给它“创新成立”。单纯加入记忆、做预测状态监督或使用平衡坐标，不足以成为新主方法。

## 1. 旧证据支持什么，不支持什么

- `mathematical_reconstruction_20260927/REPORT.md` 已验证：L1 一对真实末端编码距离为 1.089350，原生预测仅为 0.023134。真实输出编码能区分这一对后果，因此不能笼统声称“视觉 encoder 已经丢掉了动作后果”。也不能由输出可分推出初始状态编码或三帧缓存已充分。
- 原生自产推演和真实历史条件预测的差距，既可能来自表示不闭合，也可能来自错误转移、分布偏移、监督与使用不一致。仓库 `THEORY_CANDIDATE.md` 已给出完全可观测系统的反例，见下文。
- `object_response_constraints_20260927/REPORT.md` 表明几何不穿透与裸轨迹线性组合不充分；它们没有识别出缺失记忆或正确的状态坐标。
- `rwm_task_iteration_20260928/REPORT.md` 表明适配后的一步监督可改善旧保留集，却使多分支完整推演恶化。它没有证明非马尔可夫性，也不要求我们继续改变在线适配度量。

因此，下面的数学对象是在竞争性解释中形成解法，不是在为一个已经确认的“记忆缺失根因”命名。

## 2. 精确的未知量：什么状态值得被递推

先考虑确定性受控系统 `x_{t+1}=T_a(x_t)`，目标输出为 `y_t=g(x_t)`。选择表示 `s=E(x)` 后，一个精确闭合的受控实现要求存在 `F_a` 与 `G`，使

\[
E\circ T_a=F_a\circ E,\qquad g=G\circ E.
\]

等价地，任何被 E 合并的两个状态都必须在同一动作后仍被 E 合并，而且当前目标输出相同：

\[
E(x)=E(x')\Longrightarrow
E(T_a x)=E(T_a x'),\quad g(x)=g(x'),\quad\forall a.
\]

这比“重建当前图像不错”强，也比“把不同动作的 latent 拉远”准确：实际等效动作应允许相同后果。

在只有视觉历史 `h_t=(o_{0:t},a_{0:t-1})` 的情况下，不假定物理 x 可见。定义两个历史等价，当且仅当它们对所有允许未来动作序列 U 的目标输出分布相同：

\[
h\sim h'\iff
\mathcal L(Y_{1:H}\mid h,\operatorname{do}(U))
=\mathcal L(Y_{1:H}\mid h',\operatorname{do}(U)),\quad\forall H,U.
\]

未知状态是这个等价类的一种可计算坐标，而非必须保存所有历史。这里使用 do 只是澄清“主动执行给定动作”的含义；它不赋予既有被动数据免费的因果识别能力。若动作由未记录因素决定，仍需额外识别条件。

经典预测状态表示以未来动作—观察实验的条件成功概率作为状态坐标；系统动力学矩阵的行对应历史、列对应测试，有限秩时可选核心列形成线性预测状态并递推。这是已有结果。[Littman、Sutton、Singh，2001](https://proceedings.neurips.cc/paper/2001/file/1e4d36177d71bbb3558e43af9577d70e-Paper.pdf)；[Singh、James、Rudary，UAI 2004，§2–4](https://arxiv.org/pdf/1207.4167)。连续图像和动作并不能自动继承离散有限秩假设；核条件嵌入已有对应扩展。[Boots 等，2013](https://arxiv.org/abs/1309.6819)

**算法上的实质变化**可以是离线联合学习 `E,F,G`，使状态的含义由未来作用响应决定，部署时只初始化状态并执行固定转移。它完全不需要在线优化权重。普通 RNN 也能实现这一计算，区别只能来自可辨识的状态构造、结构约束或可证明/实测的外推优势，不能来自换一个“状态”名称。

## 3. Mori–Zwanzig 在此处的位置：解释闭合，不能代替识别

把一个线性受控系统分成保留坐标 q 与未解析坐标 r：

\[
q_{t+1}=A_{a_t}q_t+B_{a_t}r_t,\qquad
r_{t+1}=C_{a_t}q_t+D_{a_t}r_t.
\]

直接消元给出

\[
q_{t+1}=A_{a_t}q_t+
B_{a_t}D_{a_{t-1}}\cdots D_{a_0}r_0
+\sum_{j=0}^{t-1}B_{a_t}D_{a_{t-1}}\cdots D_{a_{j+1}}C_{a_j}q_j.
\]

空乘积取 I。记忆核依赖整段动作顺序，一般不是固定时间卷积；也不能删掉初始未解析状态的项后宣称精确闭合。这个式子由当前线性模型直接消元得到，不把它误归为某篇自主系统论文的受控定理。

Mori–Zwanzig 的作用是系统地组织类似的 Markov 项、记忆与未解析初始条件项。Lin 等的推导与数据算法专门讨论自主系统，且精确恒等式不意味着有限数据下可识别闭合核。[Lin 等，§2–5](https://arxiv.org/html/2101.05873v3)。学习闭合及记忆模型已有直接研究。[Pan 与 Duraisamy](https://arxiv.org/abs/1803.09318)

在我们这里，把这条式子写成 `F0+memory` 会再次回到已被质疑的预设。合理用途是判定：保留的状态是否需要扩展，或者是否存在更有效的受控状态坐标。若普通三帧/长历史模型已足够，就没有必要把记忆升级为主机制。

反例复述：真实 `x_{t+1}=x_t+a_t`，模型 `f0(x,a)=0.7x+a`，状态完全可见。首步动作 1 与 2、随后 9 步零动作，真实终点差为 1，模型仅为 `0.7^9=0.040353607`；真实历史条件预测显著较好。这里不存在隐藏状态，修复错误系数即可。因此当前两项现象不能识别 nonclosure。

## 4. 更贴合当前困难的经典对象：输入—输出传递算子

稳定离散 LTI 系统

\[
x_{t+1}=Ax_t+Bu_t,\qquad y_t=Cx_t
\]

的可达与可观测算子分别为

\[
\mathcal C=[B,AB,A^2B,\ldots],\quad
\mathcal O=[C^T,(CA)^T,(CA^2)^T,\ldots]^T.
\]

Hankel 算子 `H=O C` 把过去输入的作用映射为之后的自由输出；它跨过了状态坐标这一人为选择。令

\[
W_c=\sum_{k\ge0}A^kBB^T(A^T)^k,\quad
W_o=\sum_{k\ge0}(A^T)^kC^TCA^k.
\]

Hankel 奇异值为 `sqrt(eigenvalues(Wc Wo))`。平衡坐标按既能被输入影响、又会影响未来输出的程度排序，而非只按状态方差排序。经典稳定 LTI 平衡截断在相应标准假设下保稳定，并提供输入输出误差界；这些条件不能直接推广到接触切换、视觉非线性或任意学习到的矩阵。[MathWorks 官方文档](https://www.mathworks.com/help/control/ref/mor.balancedtruncation.html)

这提供了一个比“更平滑的预测”更合适的计算标准：**删去不影响未来作用结果的自由度，保留低方差但对后果有影响的自由度。** 稳定与后果可分并不必然冲突；冲突可能来自选择了错误的压缩或误差度量。

然而，既有近邻非常接近：CoBRAS 已平衡状态协方差与未来输出梯度协方差，专门处理低方差高敏感方向，并构造斜投影及核坐标。它需要真实高阶动力学的梯度/伴随信息；用错误 F0 的梯度替换并不会继承其真实性。[Otto 等，§1–3](https://arxiv.org/html/2207.14387)。受约束自编码器也已学习非线性投影并考虑动力学。[Otto 等](https://arxiv.org/html/2307.15288)。核空间中的非线性受控平衡降阶同样已有研究。[Bouvrie 与 Hamzi](https://arxiv.org/abs/1011.2952)

所以“引入平衡截断/平衡 autoencoder”不是尚无人做的创新。剩余问题是：在只有合法视觉—动作样本、缺少真实状态与真实伴随的条件下，怎样估计足够可靠的响应重要性，并构造可递推、可组合的状态；以及这种构造为何优于同信息的标准多步预测学习。

### 输出不能为结果服务

y 的含义、单位和权重必须在看方法结果前固定，并向所有基线开放。若任务是完整视觉后果，不能把它悄悄改成形心误差；若选择物体交互输出作为局部研究对象，需另行验证对完整任务的贡献。推杆通道可能幅度大且容易预测，但不能仅因它“太容易”就事后删除；应预先指定任务相关输出并报告全量结果。用待评价分支真值学习该分支的投影或输出权重属于泄漏。

## 5. 可复算例子：稳定模型也可能保留错误的状态方向

取

\[
A=\operatorname{diag}(0.2,0.9),\quad
B=\operatorname{diag}(5,0.2),\quad
C=\operatorname{diag}(0.02,5).
\]

两种输入独立、输出二维、初值为零。**C 为对角矩阵，不能替换成单行，否则 Wo 出现交叉项，下面数字不再成立。**

| 量 | 第一状态 | 第二状态 |
|---|---:|---:|
| Wc 对角元 | 625/24 ≈ 26.041667 | 4/19 ≈ 0.210526 |
| Wo 对角元 | 1/2400 ≈ 0.000417 | 2500/19 ≈ 131.578947 |
| Hankel 奇异值 | 5/48 ≈ 0.104167 | 100/19 ≈ 5.263158 |
| 各输出通道的 H∞ 增益 | 1/8 = 0.125 | 10 |

白噪声输入下，按状态方差的一维 POD 会保第一状态；一维平衡截断保第二状态。两种截断都稳定，但前者丢掉的输入输出映射 H∞ 范数为 10，后者为 0.125。这个例子证明的是度量不一致可以造成“稳定却失去重要后果”，不是证明原生 JEPA 的失败机制。

实际用 Fraction 计算得到以上分数。复算片段：

```python
from fractions import Fraction as F
A=[F(1,5),F(9,10)]; B=[F(5),F(1,5)]; C=[F(1,50),F(5)]
Wc=[b*b/(1-a*a) for a,b in zip(A,B)]
Wo=[c*c/(1-a*a) for a,c in zip(A,C)]
HSV=[b*c/(1-a*a) for a,b,c in zip(A,B,C)]
gain=[b*c/(1-a) for a,b,c in zip(A,B,C)]
assert Wc == [F(625,24),F(4,19)]
assert Wo == [F(1,2400),F(2500,19)]
assert HSV == [F(5,48),F(100,19)]
assert gain == [F(1,8),F(10)]
```

## 6. 可复算例子：状态坐标由响应定义，不意味着新网络

令 `q'=q+a v, v'=v`，只观察 q。`(q,v)=(0,1)` 与 `(0,-1)` 当前图像相同；执行 a=1 的后果分别为 ±1。任何只看 q 的确定性预测器，在这两个等权状态上的一步 MSE 至少为 1。

选择两个探测动作的预期响应作为状态：`r+=q+v, r-=q-v`，则

\[
\begin{bmatrix}r_+'\\r_-'\end{bmatrix}
=\begin{bmatrix}1+a/2&-a/2\\a/2&1-a/2\end{bmatrix}
\begin{bmatrix}r_+\\r_-\end{bmatrix},\qquad
q=(r_++r_-)/2.
\]

这是固定的离线动力学实现，不是每一步在线修正。对 `q,v,a,b∈{-2,-1,0,1,2}` 共 625 组，已用 Fraction 验证两步递推严格等于真实 `q+(a+b)v` 及对应两个响应坐标。

但它并没有击败普通状态估计：只要过去某一步动作 a 非零，就能从 `v=(q_t-q_{t-1})/a_{t-1}` 得到同样状态；长历史模型/RNN 当然能学会。若过去始终 a=0，两种 v 根本没有被观察区分，任何算法都不能从相同经历断定真实 v；正确对象需保留不确定性。这个例子用于区分“状态如何定义”“状态能否识别”与“如何实现”，不能用来申报视觉新机制。

## 7. 合法数据如何约束，怎样避免又做一轮无尽诊断

当前四案失败池可作为回归，不能单独识别受控实现。短经历只展示一条实际动作路径；未执行测试的响应不是已知标签。可用信息有两种：

1. 已完成的离线动作—视觉序列，在动作覆盖/采样机制适当时，用于学习实际被执行后果及共享转移。只在已覆盖动作和输出族内宣称可识别。
2. 预先指定、从同一起始条件执行的训练分支。它们可以约束受控响应矩阵，但必须与最终评价分支、起点及组合隔离；不是在线查询答案。若不允许新采集，应明确当前资产无法提供这些反事实对照，而不是用 F0 生成“真值”。

一个有去留标准的形成实验足够，目标是判断新状态构造是否带来可迁移能力，而不是穷尽失败原因：

- 固定一组动作前缀和后缀、固定视觉输出定义，训练只见部分组合，评价未见组合及较长串接；同时含真实后果应分开和应等效的动作。
- 同信息比较：冻结视觉特征的强转移头；相同历史/瓶颈/训练预算的 RNN 或 Transformer；标准多步自产训练；响应状态/受控实现候选。若候选用了额外分支监督，基线也必须获得。
- 检查完整后果、动作后果差、未见组合误差和共同前缀一致性。只有真实后果差分作为目标，不能奖励“距离越大越好”。
- 把状态初始化和转移分开评估：相同真实输入下仍失败是转移/表示候选问题；真实历史可正确初始化而自产失真，仍可能是学习转移错误，不能自动判为缺记忆。
- 新鲜起点是主要裁定，旧四案只作回归。不要把密集候选对当独立样本。

**放弃这一机制的条件：**同信息普通多步模型已解决组合外推；候选优势在开放相同分支监督后消失；必须依赖查询后果/真实伴随才构造状态；只改善选择不改善所声称的响应；或理论要求低秩/闭合而新增测试持续暴露未建模响应。任何一种都足以停止把这一实现扩成主论文。若只剩“多步训练更好”，应保留为基线而非包装成新的受控实现理论。

## 8. 与过去版本的实质边界

过去的默认未知量是固定表示上的 `ΔΘ(D)`；本候选的未知量是 `E、F、G` 及可验证的输入输出关系，训练数据可以在离线塑造整个计算过程。保留动作后果、共享规律和组合一致性的任务约束，但不继承“必须冻结表示、必须在线拟合、必须加回原生输出”的实现选择。

目前仍缺从视觉样本到可靠响应坐标的具体新算法。应把这个空缺公开保留，并与其他应用数学重建竞争；不能因为术语已经换成 Hankel、closure 或 realization，就认为完成了用户要求的底层重新建模。
