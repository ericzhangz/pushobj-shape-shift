# 原生交互时机验证：独立审查底线

2026-09-27。已读 MAINLINE_PROPOSAL.md 与 MECHANISM_RECONSTRUCTION.md；未使用 skills，未跑 GPU。以下是本轮形成验证的解释合同，不要求先完成大规模训练。

## 1. 什么结果才能称为原生时机错误

- 来源必须是当前 F0 的逐步原生 rollout，以及同起点、同动作、同时域的真实轨迹。旧接触参照、学生或物理代理出错不计作 F0 出错。
- 分开记录推杆到达/自身运动、物体开始响应、几何接触三种事件。物体运动不等于接触，几何距离近也不等于有效作用。标签名称必须对应实际观测量。
- 预测事件区间与真实事件区间在计入读出误差后不相交，才支持该个案“时机可分辨地错误”。重叠应写无法分辨；不得把区间中点的细小差异当成精确事件延迟。
- 有事件错误只支持关联性诊断。要说其导致候选差距，需要可保持 F0 的作用通道干预并完整重新递推；末端改分、轨迹重采样都不够。

## 2. 读出校准底线

- 冻结几何/运动读出、阈值及拟合数据来源；优先复用已有独立校准，不用本批终点成败调整阈值。逐形状报告推杆、物体位置/姿态误差及事件邻域的误差，均值不能替代尾部/最大误差。
- 至少在真实 RGB 编码的 latent 上校准同一个读出，检查它能否恢复本轮真实事件。真实编码都读不准时，预测 latent 的事件不能解释为 F0 的错误。
- 不设凭空通用“必须小于 1 px”的标准。可操作要求是：校准误差传播出的几何区间足以区分接触/不接触，以及时间误差小于拟声称的时差。若距离误差界为 e_g，局部速度为 v，其时间不确定性至少约为 e_g/|v|；接近零速度时标记不可辨。
- 校准的经验分位数只是覆盖率陈述，不能当严格误差界。用保守区间或同时报告阈值/误差敏感性；保留所有失败读数和覆盖率。
- 真实编码校准不能证明预测 latent 上的读出无偏。报告预测 latent 是否明显越出校准域、几何是否物理可行；异常值标为读出不可靠，不能将其自动归为事件病因。可先得到“冻结读出下的预测事件差异”这一有限结果，无须为此停掉整轮。

## 3. 每 5 个环境子步一个宏采样的可判与不可判

- 使用实测时间映射。若只有宏端点采样，0→1 仅将事件定位在相邻宏时刻之间，宽度为 5 个子步；不能宣称 1 个子步精度。
- 一个宏区间内发生开始又结束，端点标签可能完全看不见；两次接触的顺序、持续时长及擦边事件通常不可辨。不得把未检出直接记成从未接触。
- 若子步真实轨迹可得，可以精细标记真实事件，但原生预测仍只有宏输出，应保留不对称分辨率。不能插值出不存在的原生子步预测。
- 没有接触、事件超出时域、读出失败、已有接触的左删失和未结束的右删失分开编码，不能用零时刻或统一 NaN 填成普通回归样本。

## 4. 共享边界与固定延迟的无泄漏比较

- 先冻结 D、查询起点 h、候选 U、支持/查询划分及局部几何匹配规则。一个 D 的合法观测只拟合一份边界偏移；不得逐查询再校正。
- 统一符号：delta_tau = tau_true - tau_F0；拟合 delta_b = v_D * delta_tau_D 后，预测查询 delta_tau_U = delta_b / v_pred_U。v_pred_U 必须来自封存前可获得的原生预测或独立合法自运动模型，不得用查询真实事件处的目标速度算预测并称为迁移。
- 查询真实速度可用于事后关系图 v_true * delta_tau，必须明确标成描述性 oracle 几何检验，并和可部署预测结果分开。它不证明合法 D 能迁移。
- 速度必须是同一个边界函数的穿越速度；命令幅值通常不是它。未知局部法向或不同接触面不得硬配。正负方向一致，近零速度和事件新增/消失单列，不靠裁剪分母掩盖失效。
- 支持事件时间也是区间时，delta_b 与查询事件预测应传播成区间；允许报告区间距离/覆盖率。若不同速度候选不足，结论是该对比尚不可检验，保留已完成的原生诊断。
- 无修订、固定时间偏移、边界偏移必须共享 D 和同一查询集合。若当前样本已反复用于开发，全部标为开发诊断，不能转称独立确认。

## 5. 代价差图、符号与样本单位

- 冻结 cost 定义并注明越小越好。横轴 x = J(U)-J(V)，纵轴 y = Jhat(U)-Jhat(V)；x*y<0 为严格反序，接近零的 tie 单列。修订箭头从 y0 到 yD，不得交换真值/预测轴来营造改善。
- 沿用 E0 = x-y0、K = yD-y0，验证 ED = E0-K 与 ED^2-E0^2 = K^2-2*E0*K。视觉 latent cost、几何目标 cost、实际 success/regret 分开；不能混称真实任务代价。
- 一个候选池只取无序对 U<V，反向对不是新样本。同一分支的多 horizon、多目标及成对展开均相关；先按同起点候选池汇总，若做区间应按独立 episode/起点聚类，不按 pair bootstrap。
- 原生诊断阶段没有 F_D 时，只能画原生散点及关联诊断，不能画假想修订箭头。已有修订的箭头需真实重新 rollout，不用“校正后的预测时刻”直接合成终点。
- 报告每个起点的全部预选候选、排除原因、ties、可辨事件覆盖率。不能只呈现被事件假说解释的反序对。
