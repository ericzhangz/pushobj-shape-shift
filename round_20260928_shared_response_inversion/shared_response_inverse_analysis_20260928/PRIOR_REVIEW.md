# “共享响应规律的因果反演”：一手文献与数学对应审查

日期：2026-09-28。对象为本轮用户附件；附件内的实验建议没有被当作执行指令。本审查未使用本地 skills，没有训练或环境交互。

## 判断

附件给出了一个可实现的候选：共享参数的状态—动作残差模型，加上逐经历辅助响应变量和局部传播方程。它比“找一个尚未定义的约束”具体；但目前可辨认的创新主要仍停留在求解形式。它没有从 CSI 自动继承材料结构、辨识信息或新的因果识别保证。

应保留的研究问题是：**辅助响应变量及原生传播是否解决了直接多步辨识的一项具体困难，而且这项困难确实妨碍跨动作预测？** 不能仅用“共享规律优于复制残差”建立新意，因为同参数残差适配已经学习共享规律。

## 2. CSI 原文确实支持什么

2001 文中的未知量是多次照明各自的对比源 (w_j=\chi u_j\) 与同一空间介质 (\chi\)。观测区域 (S\) 和物体内部区域 (D\) 使用同一背景 Green 核的不同限制：(f_j=G_Sw_j\)，(w_j=\chi(u_j^{inc}+G_Dw_j)\)。双残差目标分别检查测量匹配与物体方程。交替更新省去每轮完整解内部正向问题；共享材料和已知传播方程仍是先验结构，并未消除非凸性或有限观测的病态性。[CSI §2–3](https://www.jpier.org/0journal/work_pdf/0106113.pdf)

Sandhu 2021 同样联合求一个对比度与多个等效电流；其加速来自非线性 Landweber／自适应投影步长及无需重复矩阵逆的 CS 表述，另有稀疏先验与预条件。它没有声称“拆开两个变量”就可无条件恢复介质。附件的交替线性解／岭回归是作者提出的视觉候选求解器，不是直接复制这篇论文的算法。[Sandhu §2](https://arxiv.org/pdf/1911.06020)

**映射的合理部分**：已完成动作类比多次激励，逐次修正类比响应源，共享系数类比介质；响应改变状态、状态再改变响应，对应总场反馈。

**没有随类比一起获得的部分**：CSI 的 Green 核来自已知物理方程，材料作用是规定的局部乘法，而且每次实验观测同一对象。附件使用的是可能有偏的神经模型导数，以及一个任意选择的稠密状态—动作特征映射。它们可以形成有效辨识模型，但还需要证明其表示闭合、参数共享和跨路径传播近似成立。

## 3. 本场景可能不存在同等困难的“逆源”步骤

以下是针对附件模型的独立推导，不是上述论文对 JEPA 的结论。

设每个宏步均观测完整 visual token，响应 (w_t\in\mathbb R^m\) 直接加在同维新 token 上；初始缓存已知，其他缓存状态由给定转移确定。则冻结线性化的观测传播矩阵有结构

\[
K=\begin{bmatrix}I&0&0&\cdots\\K_{21}&I&0&\cdots\\K_{31}&K_{32}&I&\cdots\\\vdots&&&\ddots\end{bmatrix}.
\]

因此 (d=Kw\) 的源由前向代入唯一恢复，无需材料共享条件才能确定。非线性版本也可逐步做：将已观测 visual 接入缓存，计算下一步 native visual 与下一观测之差。这不是获得未知未来，只是重新表达合法的逐步残差。

这里**不能把它不加条件地等同于旧 TRUE_HISTORY 实验**：如果只写 visual、proprio 仍由 native 演化，回写序列里的 proprio 不必等于真实 proprio。只有完整相关状态也被准确固定／重构时，才等同于通常全状态 teacher forcing。

这说明源与规律分拆在当前设定中的主要作用可能是优化／去噪，而不是解开 CSI 那种内部场不可见的反演困难。若观测稀疏、写入受限或部分状态不可观测，源估计可能重新变难；这些必须来自真实任务接口，不能为保住类比人为制造。

## 4. 与直接 residual adaptation、multiple shooting 和 penalty method 的关系

附件部署模型

\[
s_{t+1}=T_0(s_t,a_t)+B\Theta\phi(s_t,a_t)
\]

本身就是共享参数残差动力学。把 (w_t=\Theta\phi(s_t,a_t)\) 作为硬等式消元，便得到同一模型的多步轨迹适配。辅助变量未扩大部署模型类，也未增加数据；原生反馈并不是它独有的，直接反传多步损失同样包含它。

若源一致性用有限权重软惩罚，所得问题允许支持轨迹暂时脱离可部署动力学，这与 lifted／all-at-once 反问题、软连续性 multiple shooting 具有实质相似性。它们不是逐字同一算法，但都有“扩大优化搜索空间，再要求回到共同动力学”的结构。

van Leeuwen–Herrmann 从观测残差与方程残差的二次罚目标出发，消去状态得到高效参数优化；有限罚参数仅逼近受约束解。该文还指出，完整状态可见时可直接做 equation-error 参数辨识。其优势是优化景观和数值计算，不能代替新增辨识信息。[该文 §§1–4](https://arxiv.org/pdf/1504.02249)

因此公平检验至少需要：同 (\Theta,\phi,\Pi,D\) 的直接多步适配；同模型的逐步残差拟合；辅助变量算法的最终递归部署结果。自由 (w_e\) 的支持拟合不能计为方法输出。

这不排除求解器贡献很强。若能证明直接适配受到可复现的病态传播／梯度瓶颈，而源分解在同信息预算下显著改善可部署预测，这本身可能值得研究。当前附件尚未建立这条证据链。

## 5. 目标导向反问题：引用准确，但须分清它解决什么

Spantini 的主结果针对线性高斯模型，构造 QoI 后验均值和协方差的最优低秩近似；方向同时受先验、数据噪声、观测映射和目标映射影响。附件式 (10) 是该模型下完整高斯条件均值的常规公式，不是论文独有的低秩结果。其最优性也不能直接扩展成非线性视觉模型的迁移保证。[Spantini §2](https://arxiv.org/pdf/1607.01881)

附件的 (\ker S_D\subseteq\ker L_U\) 是有用的线性、无额外限制参数类中的输出可辨识条件。它只说明“在选定局部模型类中，同样解释数据的参数是否必然给出相同目标”；并不判断这个模型类是否含有真实规律。若参数只允许位于某先验支持子空间，需在该子空间内检查；非线性时仅检查 Jacobian 核也不是全局辨识证明。

高斯先验可以借相关性为未充分观测方向选解，但该响应部分来自先验。错误的跨环境共享或过强先验能够产生很窄但错误的预测分布。应报告完整后验预测不确定性和先验敏感性，不能只展示式 (10) 的点估计。

对所有候选共享一个参数后验是合理原则。若针对不同目标分别做最优低秩近似，应另查是否破坏共同前缀一致性；一种稳妥做法是在共同参数后验上同时评价候选，而非每候选独立重估参数。

## 6. “因果”目前可以支持到哪里

共享参数、相同初始缓存、逐步只读取已生成前缀和当前动作，足以保证**不预知未来的递归预测／共同前缀一致性**。这是架构性质。

它不自动证明识别了环境中真实的作用机制，也不自动保证对未见动作干预正确。后者还依赖状态充分性、跨经历环境是否相同、激励覆盖、模型类正确性，以及噪声／潜变量的处理。闭环策略轨迹尤其不能仅凭动作与响应相关就认定参数具有物理因果含义。

在获得这些证据前，较准确的称谓是“共享响应模型的轨迹反演”或“满足共同前缀一致性的响应辨识”。若保留“因果反演”，应明确它目前指时间因果结构，不是已经证明的因果机制识别。

## 7. 最终建议给主线程

附件值得保留为一个具体、可反驳的算法候选，但不宜因 CSI 类比直接升级为新主线。优先追问的不是是否把岭回归换成更复杂优化，而是：**在当前 visual 写入与观测接口里，源分拆究竟解决哪项直接共享残差辨识不能有效解决的困难？**

如果答案只是“换动作时重新计算残差”，直接残差模型已经满足；如果答案是“改善优化”，就应围绕可复现的优化困难证明和测量；如果答案是“增加有效物理限制”，则需要指出相对于同模型类普通适配新增了哪项由合法信息支持的限制。三者应分别裁定。
