# 共享响应规律反演：原生形成验证

2026-09-28。执行用户授权的形成验证：固定响应模型与数据，比较普通多步适配和附件提出的辅助源反演，再评价实际自由推演。本轮未使用本地 skills；沿用现有 observation_transition 主路径，未修改 backbone 或创建替代世界模型。

## 1. 结论与去留

**当前这个“稠密共享响应模型＋CSI 式源分拆”构造，不晋升为主论文机制。源分拆没有显示优化或计算优势；相对于共同离线先验，在线共享响应适配尚未稳定改善完整后果。**

这轮已经运行实际模型、响应参数辨识和封存后的独立评分，超出了概念或代数分析。结论限定于当前特征、先验、两步支持和八轮源求解，不否定全部逆问题方法，也不改变“从已完成经历修订未执行动作后果”的主问题。

三个最重要的结果：

- 同一模型类的 DIRECT 在四案都取得更低的实际部署支持目标，耗时均短于源求解；其优化器没有触及迭代上限。
- 主源方案 μ=1 的辅助拟合误差与实际部署误差相差约 4.04–13.51 倍，之前的风险在原生模型上确实出现。
- DIRECT 的末端候选后果差分误差比 NATIVE 降低 13.73%，固定池 regret 降低 88.01%，但全未来视觉误差上升 2.42%。两个源方案相对 NATIVE 在这三项上均改善；但相对共同 PRIOR，它们的完整视觉误差仍上升，未体现独立的全面收益。

最有用的新诊断是：候选之间的相对误差可以下降，同时候选共同的平均误差增加。仅看到分支差异恢复或选择改善，不能认定完整响应规律已被修复。

## 3. 模型与求解器真正做了什么

固定模型为

\[
s_{t+1}=\Psi_0(s_t,a_t)+B\Theta\phi(s_t,a_t),\quad
\phi=[1;s/\sqrt{1212};a/\sqrt{10};(a\otimes s)/\sqrt{12120}].
\]

s 是原生三帧 404 维缓存的展开；未压缩，Θ 为 384×13343，共5,123,712个系数。B 只写新 visual，后续 proprio 由原生模型耦合传播。缓存更新与动作写入均继续走同一个 rollout。

离线先验以真实历史的一步残差做岭回归；α 从固定网格 {0.1,1,10} 按整 episode 留一验证选择，两个形状均选10。随后在各自十条离线经历重拟合。在线各方法共用该 ΘΠ、相同 φ、D 和 λ=10。验证只决定这张小网格里的设置，不代表 α 的全局最优，也不保证离线先验跨动作正确。

在线硬目标是两步实际自由推演的 visual 平方误差总和，加 λ‖Θ−ΘΠ‖²。DIRECT 使用 L-BFGS 和真实非线性多步反传。源码中的除以768只统一数值尺度，不改变相对正则强度。

源方案实际实现了附件的局部式（5），没有用另一个残差 RNN 代替它。H2 时

\[
K=\begin{bmatrix}I&0\\J&I\end{bmatrix},\qquad
A_\Theta=\begin{bmatrix}I&0\\-Q_\Theta&I\end{bmatrix}.
\]

J 是第二步原生 visual 对第一步写入源的精确自动微分；QΘ 是相同变量对第二步共享响应的导数。每轮刷新 J 和仿射偏置，双精度求解768维线性系统；按真实非线性联合目标回溯接受源，再用 λ/μ 的精确对偶岭回归更新 Θ。主设置 μ=1，预先固定压力检查 μ=10，各运行8轮。

双方都从同一先验开始；源初值由先验自由推演产生。最后选择各自迭代过程中实际硬支持目标最小的 Θ，不看查询标签；源最后一轮 Θ 另行保存。辅助源 w 没有用于候选部署。

完整冻结协议见 [RUN_PROTOCOL.md](RUN_PROTOCOL.md)，代码见 [formation.py](formation.py)。此前审查中讨论的非线性源 L-BFGS 是备选；实际运行的是上面的局部线性系统与回溯。

## 4. 查询结果：六种方法

以下为四案等权平均；全视觉误差覆盖五步，后果差分覆盖每案28对候选的末端 visual 差向量。regret 为固定候选池上的真实代价差，越小越好。

| 方法 | 全视觉 MSE | 末端后果差分 MSE | 代价差 MAE | 平均 regret |
|---|---:|---:|---:|---:|
| NATIVE | 0.063376 | 0.121884 | 0.079941 | 0.013871 |
| PRIOR：仅离线先验 | **0.058716** | 0.114000 | **0.065087** | 0.003955 |
| STEP_RIDGE：逐步源回归 | 0.061742 | 0.108389 | 0.082811 | 0.002898 |
| DIRECT：直接多步适配 | 0.064909 | 0.105147 | 0.094781 | **0.001663** |
| SOURCE μ=1 | 0.060912 | 0.107319 | 0.079733 | 0.003610 |
| SOURCE μ=10 | 0.063202 | **0.105009** | 0.087049 | 0.002376 |

PRIOR 的优势是离线经历带来的，不能记作在线反演贡献。与 PRIOR 相比，三种在线 DIRECT/SOURCE 方法的平均完整视觉误差分别上升10.55%、3.74%、7.64%；末端候选差分却分别改善7.77%、5.86%、7.89%。

SOURCE μ=1 的视觉 MSE 比 DIRECT 好，不能据此称它修复了优化困难：它优化的是不同软目标，实际硬支持目标更差，且在完整视觉 MSE 上仍不及 PRIOR。该差别与不同正则化效果相容，本轮没有进一步识别唯一原因。

SOURCE μ=10 的平均差分 MSE 略低于 DIRECT（约0.13%），未形成全面或稳定优势。四个开发案例不能承担统计显著性或普遍优越性主张。

## 5. 支持拟合与实际部署的落差

| 案例 | DIRECT 硬目标 | SOURCE μ=1 硬目标 | SOURCE μ=10 硬目标 |
|---|---:|---:|---:|
| T0 | **3.26970** | 4.52618 | 3.42395 |
| T1 | **16.17237** | 19.23767 | 16.67393 |
| L0 | **1.92075** | 2.05983 | 1.94615 |
| L1 | **9.36766** | 23.53286 | 10.49620 |

DIRECT 每案0.28–0.49秒，平均0.401秒；SOURCE μ=1 平均3.567秒，μ=10平均3.318秒。它们并非等计算量；源法每个配置需要3,072个 VJP seed，不能把8轮与100轮上限直接相比。

DIRECT 实际只用了15–23次 closure、8–14次迭代，未达上限，末尾目标已经基本不变。因此当前没有理由把源法表现解释为“普通直接适配优化不足”。源法 μ=10 的部分曲线仍在下降；本轮只说明当前8轮未显示优势，不宣称所有源求解已经收敛或被否定。

主源设置 μ=1 的四案“实际部署 MSE / 辅助源 MSE”分别为5.90、4.67、4.04、13.51。L1 最明显：

- 辅助源支持 MSE：0.002152。
- 只保留最终 Θ 后自由推演的支持 MSE：0.029071。
- 同类 DIRECT 的支持 MSE：0.005969。

提高 μ 至10缩小落差，但没有得到新的全面迁移优势。不能将辅助轨迹的漂亮拟合解释成共享规律已经学会。

## 6. 为什么差分变好，完整后果仍可能变差

对同一案例的 n=8 个候选，令 eᵢ 是预测与真实的 visual 误差向量，ē 为候选平均误差。使用相同的维度归一化，有

\[
\frac1n\sum_i\|e_i\|^2
=\|\bar e\|^2+\frac1n\sum_i\|e_i-\bar e\|^2.
\]

候选对差分误差只测第二部分，平均全对平方误差等于第二部分的 2n/(n−1)=16/7 倍。这个恒等式不是新理论；本轮在全部案例/方法的缓存上核对，分解残差小于10⁻¹²。

末端四案平均分解如下：

| 方法 | 候选共同平均误差项 | 候选差异误差项 | 总末端误差 |
|---|---:|---:|---:|
| NATIVE | 0.031366 | 0.053324 | 0.084691 |
| PRIOR | 0.031197 | 0.049875 | 0.081072 |
| DIRECT | 0.039279 | 0.046002 | 0.085280 |
| SOURCE μ=1 | 0.034668 | 0.046952 | 0.081620 |
| SOURCE μ=10 | 0.037829 | 0.045941 | 0.083770 |

因此 DIRECT 的改善不是完全虚假的：候选之间的相对误差确实降低了。但候选共同的平均误差增加，抵消了这一收益。这是当前八候选池中的潜空间分解，不应直接解释为某种已识别的物理偏移或唯一失效原因，也不自动推出应当增加哪种新正则项。

L1 还给出支持到查询的具体反例：DIRECT 把支持视觉 MSE 从 PRIOR 的0.068975降至0.005969，查询视觉 MSE 却从0.166955升至0.192323。支持拟合能力已被展示，迁移正确性没有随之成立。

- 缓存编码路径相对实际原生 rollout、零响应相对原生预测：通过，最大差低于2×10⁻⁵。
- 完整源传播方向导数对有限差分：最大相对检查误差约7.61×10⁻⁴。
- 第二步响应特征反馈的解析 QΘ 对方向差分：最大检查误差1.70×10⁻⁶。
- 固定源后的岭更新：四案真实联合目标均不增加。
- PRIOR、STEP_RIDGE、DIRECT、两种 SOURCE：改变动作后缀时，公共 observation 前缀逐值相同。
- backbone 参数和缓冲区版本未变；预测先封存，再由独立评分程序读取查询后果。
- 独立 CPU 审查完成4,460项逐行到汇总的算术与选择关系核对。

评分实现有两处修正，原运行版与结果均保留：

1. 初版评分传入 objective step=2；当前六帧路径下 step2和step4都进入相同 terminal 分支，32条真实路径逐值检查为零差。已改为step4并显式断言 terminal，重新评分。
2. 原 encoder module hook 因模型直接调用 encoder.forward 而漏计为0。已改为逻辑调用计数；每次评分实际32次图像编码、192帧。初版数字没有作为“无编码成本”使用。

修正后评分位于 scored_verified。所有潜空间误差、代价差、选择、regret、读出失败计数与初版完全相同；两个案例的方法形心汇总有小幅重复解码/读出差异，最大0.000777px，原差异保留。不能声称全部像素读出逐值复现。

另一项差异仍存在：旧记录真实代价与本次重新编码计算的代价，4/32超过2×10⁻⁵门槛，最大6.12×10⁻⁵。**严格旧代价重放门槛未通过。** 独立敏感性检查表明：112对候选的真实排序、四案最佳候选、各方法平均 regret 顺序全部不变；单案方法 regret 最大变化1.23×10⁻⁵。报告表格保留协议中的旧记录代价，同时提供重算敏感性，不通过放宽门槛隐藏该问题。

## 8. 对研究方向的实际调整

本轮保留了一条可工作的原生响应辨识基线，证明合法经历能够通过共享模型影响未执行动作的差分与选择；但普通多步适配已经具有这些能力。CSI 式分拆在当前实现中没有提供足够独立的优势，不继续靠扩大案例或调整 μ 将它包装成核心贡献。

下一次机制设计需要明确改变“哪些跨动作响应规律被允许”，或证明某种现有求解困难确实不可忽略。当前证据更支持优先研究前者：什么结构能使支持经历改善新动作后果，同时避免不受支持的共同误差增长。这里仍缺有根据的结构，不能直接把均值校正、更多先验或一个新损失宣布成答案。

这次停止的是一个具体候选的晋升，不是主任务。现成 DIRECT、STEP_RIDGE 和 PRIOR 将作为以后任何新机制必须面对的强对照，避免再次以“能从经历适配”本身认领贡献。
