# 共享响应形成验证：独立协议审查

日期：2026-09-28。范围：审查同一可部署模型类中，直接多步适配与辅助源交替求解的有限比较。已读前轮 REPORT.md、MATH_REVIEW.md，并与主执行者核对拟采用的原生回调、特征和数据时序。未使用本地 skills，未运行模型或环境实验。

## 1. 裁定与最小实验

方案可以执行。完整非线性源梯度优化与固定源的精确岭回归，构成合法的 lifted penalty solver。它继承 CSI 的“逐次源与共享响应分开求解”思想，但不等同于附件式（5）的冻结线性化闭式源更新。不能在报告中把二者混写。

最小比较保留三项：原生/共同先验预测；同一 Θφ 的完整非线性直接适配；完整非线性辅助源交替适配。最后一项只部署 Θ，绝不部署支持源、真实视觉缓存或自由辅助状态。全都从同一合法初始缓存自由推演。

优先回答两件事：同一响应类是否有留出后果收益；源分拆是否以合理预算改善最终部署。不要把新的状态空间模块、接触检测或第二套模型接入这个形成实验。

## 2. 实际目标必须写全

令 q=384，支持宏步总数为 N。完整缓存 s 由原生动作写入、回调和缓存移位共同组成。特征 φ 使用当前缓存与当前动作；同一个 B 只将 w 写入下一 visual token。固定支持初态与动作，定义

\[
s_{t+1}(w)=\Psi_0(s_t(w),a_t)+Bw_t,
\quad V(w)=[\phi(s_t(w),a_t)]_t,
\quad Y(w)=[Cs_{t+1}(w)]_t.
\]

完整非线性软目标为

\[
J_\mu(\Theta,w)=\frac{\|Y^{obs}-Y(w)\|_F^2}{Nq}
+\mu\frac{\|W-\Theta V(w)\|_F^2}{Nq}
+\frac{\lambda}{q}\|\Theta-\Theta_\Pi\|_F^2.
\]

这里 W 是逐步源拼接，顺序与 V 一致。若不同经历长度不同，必须预先决定逐宏步等权还是逐经历等权，并在直接法、软源法与统计汇总中一致使用；不能由失败长度决定权重。

对应可部署模型始终是

\[
s_{t+1}=\Psi_0(s_t,a_t)+B\Theta\phi(s_t,a_t),
\qquad F_\Theta(D)=[Cs_{t+1}]_t.
\]

直接法最小化

\[
J_{hard}(\Theta)=\frac{\|Y^{obs}-F_\Theta(D)\|_F^2}{Nq}
+\frac{\lambda}{q}\|\Theta-\Theta_\Pi\|_F^2.
\]

有限 μ 的软源法与直接法共享模型类，不共享训练目标。每个输出 Θ 都必须额外重算上述相同的 J_hard。软源法 query 更好、J_hard 更差，可能说明正则化或隐式偏好不同；这不能单独证明它解决了直接法的优化病态。

### 源更新的梯度边界

固定 Θ，对 w 求导时，梯度必须同时经过 Y(w) 和 V(w)。把缓存、φ 或中间 visual detach 后，只优化源的本步项，不是 Jμ 的梯度。原生骨干参数可冻结，但不得因此在预测函数外包 no_grad 而切断输入梯度。

完整非线性源目标通常没有式（5）形式的闭式解。梯度/L-BFGS 源更新应明确为近似求解真实非线性子问题，记录下降前后目标与原生调用数。没有必要为名称一致先实现昂贵的显式 K、H。

### Θ 更新的精确性与归一化

固定 w 后，缓存和 V(w) 不依赖 Θ，岭回归才是精确子问题。上面的归一化给出

\[
\alpha=\frac{N\lambda}{\mu},\qquad
\Theta^+=\Theta_\Pi+(W-\Theta_\Pi V)
(V^TV+\alpha I)^{-1}V^T.
\]

如果直接使用附件求和式，则 α=λ/μ；两种公式的差别来自归一化，不能混用。使用线性系统求解而非显式求逆。更新后重算 Jμ；数值条件正常时不应上升。

## 3. 公平初始化、先验与数据

双方均从同一 ΘΠ 开始。软源的默认初值应通过 ΘΠ 自由推演取得各步 w，因此初始源一致性残差为零，初始预测与直接法相同。使用逐步真实视觉回写得到的精确源是合法的另一种初始化，但它已经是一个算法步骤，必须单独报告调用成本及额外收益，不能悄悄给予软源法。

主执行者拟采用的 φ=[1;s/√1212;a/√10;(a⊗s)/√12120] 可以作为此次冻结的模型类。中心化均值和任何尺度统计只能来自共享离线资料。是否去中心、如何处理原生 action slot 必须在看到 query 收益前固定。不能让两个求解器使用不同的特征缩放或先验。

λ 的最低要求是两法共用。若已有冻结值，继承即可；若尚无值，在离线 leave-episode-out 上使用极小网格选一次，然后冻结，不读取四案 query 真值。可用 λ∈{10^-3,10^-2,10^-1} 作为预声明的数值探索范围，但这些数值只是有单位约定的默认网格，不是已知噪声模型；必须连同目标归一化记录。

μ=1 作为固定主试验，μ=10 作为预声明的一次一致性压力检查已足够。不要根据 query 结果继续扫描 μ。如果小 μ 的收益仅来自不可部署源，增大 μ 后消失，应如实裁定；不以增加自由度或新模块挽救这个试验。

拟延长 D 到已执行 mpc 0..3 并把查询锚点移动到 m4，在索引正确且所有支持标签严格早于 m4 时合法。必须将训练用图像/动作时间索引、m4 初始历史帧和八条分支查询标签索引写入结果。原先短 D 的标签不足结论仍成立，不能用延长后结果反称原设定已经可学。

离线窗口不能随机拆成 train/test：相互重叠的窗口须随整条 episode 分组。单条真实经历的后续片段，只验证沿其已执行动作的继续预测；不同 episode 留出才开始检验共享环境规律跨路径作用。m4 的同初态候选对照更直接检查分支差异，但四案与八候选已作为开发资料使用，不能称为独立测试集。

## 4. 三条训练曲线与实际评价

每个记录点至少分别保存：

1. 辅助观测误差 ||Yobs−Y(w)||²/(Nq)。
2. 源一致性误差 ||W−ΘV(w)||²/(Nq)。
3. 同一个 Θ 的完整自由推演支持误差及 J_hard。

另存先验偏离 ||Θ−ΘΠ||、更新范数与最大单步源范数；它们用于解释放大或数值不稳定，不应事后转成使结果好看的筛选器。部署评价中不得复用源优化阶段的真实视觉缓存。

query 指标应至少包括逐案全部候选的完整 visual 轨迹 MSE、候选后果差分误差和固定候选池真实 regret。所有方法使用相同编码器、代价函数和候选标签。平均值之外保留逐案例数值，以免一例的大变化掩盖另外几例失败。候选排序改善并不单独证明动力学修复；固定池 regret 也不是闭环任务成功率。

若已有可靠物体读出，可补充物体后果，但必须继承读出失败处理规则，不得按方法分别丢弃难解码样本。原生 proprio 不被直接修正，仍会通过历史耦合改变；应保留其预测变化作为完整路径诊断。

## 5. 预算如何计数

“相同优化步数”不构成公平预算，因为源法一步可能包含多次 line search、多个 source 内步和一次精确 LS。

至少记录：

- 原生 predictor forward 的实际 batch 调用数，以及 batch×time 的宏步 token 处理数。
- 原生反向/VJP 的执行次数和所覆盖的 time 长度；JVP 若有则单独记。
- source 内部 optimizer closure 次数、Θ 直接法 closure 次数、LS 次数与耗时。
- CUDA 同步后的训练墙钟时间、峰值显存；离线 prior 学习和标签编码作为共同成本单列。
- 诊断自由推演的调用数，与优化调用数分开保存。

比较应给出“最终部署指标—已消耗模型计算/时间”的前沿，而不只展示两个任意终点。选择一个预先固定的训练预算，必要时在同一次训练保存少数中间点。训练停止与 checkpoint 选择只读支持目标及数值健康，不读 query 结果。正式解释求解器优势前，直接法应使用合适的优化器；一次 Adam 失败不能证明其表示方式病态。小样本确定性问题优先尝试具有受限 line search 的 L-BFGS，可避免把优化器品质混同为变量分拆效果。

若 direct/source 两端模型调用预算与墙钟预算无法同时匹配，应同时呈现二者，不能隐去其中一个。少量精确 LS 的成本可以较低，这本身允许成为算法优势，但不能称为零成本。

## 6. 运行前最低实现检查

- Θ=0、w=0 的回调路径应复现原生完整 rollout；若使用 ΘΠ 作为“适配前”基线，额外保留纯原生基线。
- 对相同 Θ、同初始缓存和相同动作前缀，分开运行候选与拼接批量运行应产生相同前缀，在数值容差内一致。
- source 初值由 ΘΠ 自由推演构造时，软源路径、ΘΠ 部署路径一致，源残差为零。
- 对 w 与 Θ 各选几个随机方向，用中心差分核对自动梯度，误差随扰动减小在合理区间收敛；采用浮点精度适配的扰动，不把极小差分舍入当梯度错。
- 固定 w 的精确岭回归应使 Jμ 不增；检查法方程相对残差。
- 最终部署函数只接受初态、动作、Θ，不能接收 Yobs 或逐步支持源。

这些检查直接验证主机制，并非为可逆小改动另写全面测试。任一核心检查失败时停止收益比较，先修接口或梯度，不调超参绕过。

## 7. 去留标准

**可继续形成：** 同信息、同模型类下，最终 Θ 的自由推演改善完整后果与候选差异；源法的额外收益能在固定预算曲线和共同 J_hard 上获得解释，且不依赖未部署辅助源。四例通过仍只构成形成证据。

**只说明正则化效果：** 软源法 query 改善但共同 J_hard 更差，或 μ 改变后拟合/泛化权衡变化。可以研究这个现象，但不能直接称为更好求解同一目标。

**停止扩大当前 source-splitting 版本：** 优势只存在于辅助轨迹；部署无收益；直接法以相近预算得到同等结果；或不同初始化/固定压力检查显示结果依赖偶然优化。最后一种不能证明所有变量分拆无价值，但足以阻止把本版本扩大成主论文。

**停止并报告不可执行：** 合法支持不足、锚点标签混用、参数梯度被截断、共同前缀不一致或先验泄漏。此时不应把实施错误解释为数学方法失败。

## 9. 实际 Eq.5 实现、封存训练结果与预算复核

本节在预测封存后追加，纠正前述准备阶段与实际实现的差别。第 1、2、8 节中的“完整非线性 source 梯度/L-BFGS”是曾讨论的实现方案，**本轮并未运行这一方案**。实际代码采用 H2 支持段的局部闭式 Eq.5、逐轮重新线性化、真实非线性 joint 目标回溯，以及固定源的精确 dual ridge。没有修改实验代码、参数或已封存预测。

已只读核查 [formation.py](formation.py)、[FIT_INFO.json](FIT_INFO.json)、[TRAINING.json](TRAINING.json)、[CHECKS.json](CHECKS.json)、[PREPARE.json](PREPARE.json) 和 [SEALED.json](SEALED.json)。runner SHA256 为 `d0e4312a2ec4ab8d055c5a35ad95f84d159f01c439f6791858175aca1eadf8e0`，与封存记录一致。本审查没有读取候选真实 query 后果。

### 9.1 H2 局部方程与仿射偏置

令 f₁ 为第一步原生 visual，f₂(w₁) 为第二步原生 visual。第一步源在 f₁ 之后加入，所以第一步原生 proprio 不依赖 w₁；第二步缓存中只有最新 visual 对 w₁ 有单位线性响应。固定动作后，当前 φ 对缓存线性，因此

\[
J=\frac{\partial f_2}{\partial w_1},\quad
Q_\Theta=\Theta\frac{\partial\phi_2}{\partial w_1},\quad
K=\begin{bmatrix}I&0\\J&I\end{bmatrix},\quad
A=\begin{bmatrix}I&0\\-Q_\Theta&I\end{bmatrix}.
\]

在 w₁ᵣ 处重新线性化，代码采用

\[
d=\begin{bmatrix}y_1-f_1\\y_2-f_2(w_{1r})+Jw_{1r}\end{bmatrix},
\qquad
b=\begin{bmatrix}\Theta\phi_1\\\Theta\phi_2(w_{1r})-Q_\Theta w_{1r}\end{bmatrix}.
\]

`phi_response_jac` 的 visual 索引从 `2*404` 开始，吻合三帧缓存的最后一帧。当前动作使用第二步 packed action；状态块及动作乘状态块的 √dim 缩放，与 φ 完全对应。上述 J、QΘ、d、b 及 768 维 float64 法方程代数正确，未发现阻断错误。

局部 source 更新求解 `(KᵀK+μAᵀA)w=Kᵀd+μAᵀb`，再用真实 nonlinear joint 对步长 `1,1/2,1/4,1/8,1/16` 回溯。固定源后重新运行真实缓存计算 V，以 `ridge(W,V,λ/μ,Π)` 更新 Θ。这与当前 raw-sum 损失一致；DIRECT 仅将整个 objective 统一除以 768 供数值优化，不改变 λ 相对权重。因此，本节实际运行没有前述归一化版本的 `Nλ/μ` 因子。

离线 λ 候选实际为 `{0.1,1,10}`，按每形状十个 episode 的 leave-episode-out H1 残差误差选择；两种形状均选择 10。它被直接继承为在线 raw-sum 正则系数，并由两类求解器共用。前文给出的另一组极小网格是建议，未执行。

### 9.2 初值、检查与 checkpoint

- source 初始 w 来自 Π 的完整自由推演。四案初始一致性 MSE 为 `4.56×10^-16` 至 `7.27×10^-16`，符合两法初始路径一致。
- 缓存编码适配与普通原生 rollout 的最大 visual 差为 `2.27×10^-6`；零修正 callback 与缓存原生路径的 visual/proprio 差均为 0。
- source 输出方向导数与中心差分的相对误差为 `2.52×10^-4` 至 `7.61×10^-4`。
- DIRECT 的共同 visual 前缀检查四案均为 0。该检查在当前 runner 中只直接运行于 DIRECT；不能表述为每个 arm 都分别完成过数值前缀测试。各 source 部署使用同一 callback，并由静态代码审查支持相同因果结构。
- DIRECT 与 source 都依据支持段共同 hard objective 选择参数；source 最终迭代另行保存为 LAST，以便审计，不读取 query 真值选择模型。

### 9.3 训练 hard objective 与实际计算量

以下为共同 raw-sum `支持部署误差 + λ||Θ−Π||²`，不是软源 joint objective，也不是 query 泛化误差。

| 案例 | DIRECT | SOURCE μ=1 | SOURCE μ=10 | DIRECT 秒 | μ=1 秒 | μ=10 秒 |
|---|---:|---:|---:|---:|---:|---:|
| T0 | 3.269702 | 4.526179 | 3.423953 | 0.489 | 3.411 | 3.190 |
| T1 | 16.172371 | 19.237673 | 16.673925 | 0.358 | 3.568 | 3.477 |
| L0 | 1.920747 | 2.059829 | 1.946145 | 0.281 | 3.432 | 3.279 |
| L1 | 9.367662 | 23.532858 | 10.496197 | 0.478 | 3.857 | 3.328 |

每案 DIRECT 实际使用 15–23 次 closure、8–14 次 L-BFGS 迭代、30–46 次原生 forward，以及 15–23 个标量反向 seed，均没有触及 `100 iter/120 eval` 上限。相邻末尾 closure 的 raw objective 变化在约 `0` 至 `1.91×10^-6`；这说明本次自动停止发生在观测损失平台附近，不构成全局最优或精确驻点证明。

每案每个 source μ 使用 8 outer、98 次原生 forward、192 次 batched autograd 调用，共 3072 个 VJP seed。全部 source 步接受完整步长 1，未触发缩小步长。时间为 3.19–3.86 秒，DIRECT 为 0.28–0.49 秒；这是当前单次运行的训练计时，不是多次重复统计的速度基准。

DIRECT 在四案共同 hard objective 上均优于两种 source 配置。μ=10 相对 DIRECT 仍高 `1.32%–12.05%`；μ=1 高 `7.24%–151.21%`。μ=1 的辅助观测 MSE 显著小于自己的部署 MSE，尤其 L1 为 `0.002152` 对 `0.029071`。该差距直接说明，报告辅助拟合会高估可部署收益。μ=10 减小源缺陷，但并未在当前预算赢得共同 hard objective。

**当前无需给 DIRECT 追加预算。** 它未遇到设置上限，已经以明显较少的计算获得更低 hard objective；补预算不能修复“当前证据没有展示源分拆优化优势”这一裁定。不能为了把预算数字强行补齐而延长已自动停止的直接法。

这个判断不意味着 source 已完全收敛：μ=10 的末轮 hard objective 仍下降，也不意味着所有 source solver 必然无优势。它支持的是：本轮具体 H2、特征、先验和八轮局部更新没有证明源分拆相对直接法的优化或计算优势。如果后续 query 中 source 偶有改善，应优先解释为有限罚项和拟合程度带来的泛化差异，不能逆称已经解决了直接法的优化困难。是否存在完整后果与动作比较收益，仍需由封存后的独立 query 评分回答。
