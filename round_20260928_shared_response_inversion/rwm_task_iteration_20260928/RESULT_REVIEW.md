## 3. 失败不只来自一个案例或较长时域

| case | FIXED H5 | SCALE H5 | METRIC H5 | METRIC 相对 FIXED |
| --- | ---: | ---: | ---: | ---: |
| T0 | 0.030556474 | 0.029088256 | 0.026938731 | -11.840% |
| T1 | 0.026423411 | 0.027934027 | 0.043066038 | +62.984% |
| L0 | 0.007721822 | 0.006822303 | 0.006289024 | -18.555% |
| L1 | 0.184201184 | 0.192256086 | 0.201108920 | +9.179% |

T0、L0 改善是真实的；T1 与 L1 恶化也必须保留。T0 的首步误差比 prior 高，但 H5 反而改善，进一步说明不能用首步单指标概括整条路径。

L1 的 METRIC 首步 MSE 为 **0.112099619**，同信息 prior 为 **0.074553363**。令 e 为 prior 的首步误差、d 为 METRIC 修订，则八候选合并后：

\[
2\langle e,d\rangle_{\rm mean}=0.0301753042,\qquad
\|d\|_{\rm mean}^2=0.0073709521,
\]

总增加 0.0375462563。逐候选的交叉项 **8/8 为正**，误差变化也 **8/8 为正**。因此，对当前固定首步修正作任意正标量缩放，仍会比 prior 差；这是固定方向的诊断，不表示重新拟合任何其他度量、表示或参数都不可能有效。这里的 oracle 标量仅为评价，未用于部署。

## 4. 度量确实改变了向量，不能据此断言学对了规律

下表比较相对同信息 prior 的首步修订，合并同一案例的八条候选。比例残差为最佳单一标量拟合后的残差范数除以 METRIC 修订范数。

| case | METRIC 与 SCALE 的余弦 | 最佳比例残差 | METRIC 与同 λ、M=I 的比例残差 |
| --- | ---: | ---: | ---: |
| T0 | 0.894924 | 44.622% | 35.215% |
| T1 | 0.979782 | 20.007% | 15.720% |
| L0 | 0.997359 | 7.263% | 7.347% |
| L1 | 0.975642 | 21.937% | 21.992% |

因此，不能把整个 METRIC 实现概括为纯缩放；L0 近似同向，其他案例存在较明显的非比例分量。但这项结构差异没有产生全面收益，也没有证明物体响应语义被分离或因果关系被识别。SCALE 改变正则强度也可能旋转两个支持残差的组合，所以“方向变了”并非度量学习专属证据。

学出的四块权重为约 `[8.76575, 6.05760, 0.13779, 0.13668]`，λ≈10.9123。它们是当前归一化特征的权重，不是各信息源的实际作用量。仅凭动作块权重下降，不能将失败归因于“忽视动作”；没有进行能支持这种因果归因的干预对照。

## 6. 信息覆盖与下一步边界

元数据中，离线查询动作与支持动作的 packed L2 距离覆盖约 0.719–7.054，在线首步覆盖 0–6.219；原特征余弦范围分别约 0.156–0.969 与 0.234–0.993，范围明显重叠。这些数值只能说明查询并非逐字复用同一动作，以及特征相似性存在变化；不能据此证明分布匹配或把失败归因于分布外输入。在线零距离还包括特意设置的 repeat-action 对照，不等于与历史处于同一个物理状态。

本轮离线外层只有一步查询，且来自顺序完成经历，不是同初态的多动作干预。新实现仅检验了四块核度量的首步延拓学习；没有直接训练 H5、没有强制辨识物体响应，首步输出仍在两条支持残差张成的空间内。

可保留的研究推进是：把跨动作使用要求明确放进求解对象和验收标准。应停止晋升当前四块度量作为主论文机制，也不因这一个受限构造失败而宣告这种高层思想无效。后续若提出新的数学结构，必须说明它如何约束实际可迁移的响应，而非仅增加度量参数、挑保留集最优检查点或把 regret 改善改写成动力学恢复。
