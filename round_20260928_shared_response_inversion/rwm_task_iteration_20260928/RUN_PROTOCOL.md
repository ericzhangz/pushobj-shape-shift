# RWM 高层思想借鉴：修订运算的学习与同条件比较

2026-09-28。执行前固定。禁止本地 skills。该实验不复现 RWM，不采用其插值、IDM 或重新训练视觉编码器的方法；借鉴的是让学习目标直接检验一种明确的使用运算。

## 固定目标与研究假设

原任务不变：已完成视觉作用经历 D 修订同一个冻结世界模型，使未执行动作的完整后果、相对后果和选择改善。

旧版本：用固定特征与参数距离拟合 D，由固定特征内积决定修订怎样延拓到新动作。新形成版本：保持原响应模型与原生回写，学习参数距离的几何；离线监督直接检查“从 D 求出修订，再预测后续 Q”这一运算。

这属于标准元适配/学习核的受限实现，不能作为已成立的创新。若有效，仍须面对已有元系统辨识；若无效，不继续靠扩大度量参数或选择旧案例挽救叙事。

## 原生接口与数学对象

沿用 `shared_response_formation_20260928/formation.py` 的 `phi`、`support_view`、`cached_rollout` 和原生 `observation_transition`。部署对象始终为同一 Θ，不建立第二套状态演化。

给定原两步支持，按原 STEP_RIDGE 方法逐步钳制真实 visual，proprio 始终按原生路径生成，得到 W、V。先验记为 ΘΠ，R=W−ΘΠV。定义

\[
\Theta_D(M,\lambda)=\Theta_\Pi+
R(V^\top M V+\lambda I)^{-1}V^\top M.
\]

它精确最小化固定钳制特征上的

\[
\|W-\Theta V\|_F^2+
\lambda\operatorname{tr}((\Theta-\Theta_\Pi)M^{-1}(\Theta-\Theta_\Pi)^\top).
\]

这是原 STEP_RIDGE 的广义度量版本，不与原非线性 H2 DIRECT 目标混同。M=I 时必须恢复原 `ridge`，容差沿用 2e-5。每个案例只估计一次 Θ，跨全部候选、全部步骤共享。

M 为原四块特征（常数、状态、动作、状态×动作）的正标量块对角矩阵。令 m_b=exp(η_b−mean η)，λ=exp(ℓ)，初值 m_b=1、λ=10。对数块尺度和为零，消除 M 与 λ 的共同尺度自由度；无额外门控、裁剪或失败回退。

## 使用运算参与训练

离线已完成经历提供 D 和之后的一步 Q；Q 从其真实可见历史重新启动。外层损失为适配后 Q 的完整 visual MSE。首步关于 Θ 仿射，外层可用原生缓存和四块 2×2 Gram 精确计算，无需反传 backbone。

本资产只能提供一步外层查询，故本次实现是**首步延拓几何学习**；不能称完整 H5 推演已经参与训练。H5 仅作部署测试。

元训练样本是每形状 samples 2..9 中有26帧的经历：共14条。固定先验正则 α=10。每个元训练样本的先验从本形状 2..9 中完整排除该 episode 后拟合，全部相位窗口都排除。T8、L4 无适配后查询，可作为其他 fold 的 prior 数据，但不能充当完整 meta 样本。

本轮 samples 10..11（共4条）不用于 prior 或元优化，仅检验冻结结果。这些资产在更早工作中用过，因此仍称旧开发资产上的本轮保留集，不称新盲测。最终在线四案的共同先验只用各形状 2..9，避免保留集进入构造。

## 优化、对照与预定检查

- SCALE：仅学习 ℓ，M=I。
- METRIC：学习 η 和 ℓ，外层数据、目标、初值、优化器与 SCALE 相同。
- 两者均全批 Adam，学习率0.05，固定100步。按元训练损失最低选择参数（包括初始点）；不按保留集或在线查询结果选模型。
- 保存0/25/50/100步和全部轨迹，保留集的这些检查点只展示有限训练时长敏感性，不能挑其中最好结果替代主结果。学习率与步数是优化预算，不是提出的新机制；本轮不搜索它们。
- 非有限值或等价检查失败时显式终止；不隐藏回退到 prior 的情况。

四个在线案例保留旧的 NATIVE/PRIOR/STEP_RIDGE/DIRECT 预测作为明确的历史参照。新增五臂使用相同16条离线经历和相同两步在线支持：

| 名称 | 用途 |
| --- | --- |
| SHARED_PRIOR | 相同离线信息但不做在线更新 |
| SHARED_RIDGE_FIXED | M=I、λ=10；前版更新规则的同信息重建 |
| SHARED_RIDGE_SCALE | 只学习强度的标准元校准对照 |
| SHARED_RIDGE_METRIC | 借鉴高层思想后的最小度量实现 |
| SHARED_RIDGE_METRIC_SCALE_ONLY | M=I，但使用 METRIC 的 λ；分离几何与强度 |

旧原版 PRIOR/DIRECT 使用更多离线经历，不能与新臂当作唯一的同信息对照。新旧任务、目标、编码器、动作池和 H5 评分均保持一致。此轮不宣称已经击败合理校准的同信息 DIRECT；只有出现值得推进的全面收益，才补那项强对照。

先缓存训练16条经历的161个一步原生残差/特征；全部 meta 构造只读取已完成离线经历。预计 predictor 转移为161 + 18×5 + 4×4 + 4×5×8×5 = 1067；若执行额外等价回放，应逐项记录真实计数。固定样本转移硬上限1200，超出时失败。元参数优化200步（每臂100），在线响应是闭式拟合；不能声明“零训练”，应声明“零 backbone 训练、零环境交互”。

构造代码不得打开旧在线查询未来 TARGETS 或场景重放；仅使用旧预测包中的已知目标、动作和旧比较结果。先保存 Θ、元参数及预测散列，再由独立评分脚本读取旧查询真值。冻结 backbone 参数/buffer 版本。

保存无真值的支持/查询动作差异与特征相关性，作为是否覆盖不同动作的说明；顺序动作不同不等于同初态的因果干预。

继承旧4/32真值代价重放失败，不改变2e-5检查门槛；评分用原记录代价并保留限制。各臂锚点、代价与旧缓存回归须检查。
