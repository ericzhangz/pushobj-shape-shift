# 固定预测对上的恢复增益下界

2026-09-27。本文件是条件数学结论及旧开发数据上的隔离评价。它不是新定理、不是在线可用目标，也不是所有原生反馈修订的不可能性证明。

## 1. 明确被约束的方法类

固定同一 case、同一时刻，两候选的原生 visual token 为 p_i,p_j，真实观察编码为 q_i,q_j。考虑同一个只读取该 visual token 的修订 R；R 可以依赖这案共同的 D，但在这一固定 D 下不能另读候选动作、其他历史槽或候选身份。假设该点对上有

\[
\|R(p_i)-R(p_j)\|\le L\|p_i-p_j\|.
\]

不需要假设 R 线性、可微、幂等；也无需全局 Lipschitz 条件，单个点对的以上条件已足够。

令 e_i=R(p_i)-q_i，e_j=R(p_j)-q_j，由三角不等式

\[
\|e_i\|+\|e_j\|\ge
\bigl(\|q_i-q_j\|-L\|p_i-p_j\|\bigr)_+.
\]

再用 a²+b²≥(a+b)²/2，得到

\[
\boxed{\frac{\|e_i\|^2+\|e_j\|^2}{2}
\ge\frac14\bigl(\|q_i-q_j\|-L\|p_i-p_j\|\bigr)_+^2.}
\]

用 RMS 范数，即欧氏范数除以 sqrt(384)，结论不变；平方恰好对应 visual MSE。若要求两个目标都精确恢复且分母非零，则必要条件为

\[
L\ge\frac{\|q_i-q_j\|}{\|p_i-p_j\|}.
\]

这是“修订需要多大分离增益”的下界，**不是唯一根因的证明，也不是新物理规律**。若只要求两点误差分别≤ε，则分子换成 (||q_i−q_j||−2ε)_+。

## 2. 原生 L1 fact/g99 上的实际数值

只使用先前封存的 FULL 与对应真实编码；新程序没有拟合任何修订。全部四案×五步×28对均计算，共560行，不能将这些相关行算作560个独立样本。

| 时刻 | 原生 visual 距离 | 真实 visual 距离 | 精确恢复所需最小点对增益 |
|---|---:|---:|---:|
| 0.5s | 0.017138 | 0.015266 | 0.891 |
| 1.0s | 0.028516 | 0.035212 | 1.235 |
| 1.5s | 0.127228 | 0.120766 | 0.949 |
| 2.0s | 0.084044 | 0.886346 | 10.546 |
| 2.5s | 0.023134 | 1.089350 | **47.088** |

最后一步，在 L≤1 的状态后处理类中，两个候选的平均 visual MSE 至少为 **0.284204**。原生这对的平均末端 MSE 为0.694375；因此下界没有证明此类方法毫无改善空间，但证明它不可能把这对后果完全恢复。0.284204 是这一个点对／时刻的下界，不能代替整个数据集的平均下界。

这也补充了原先解码轮廓分化失败的证据：这里直接比较冻结编码器坐标中的后果差，未依赖 decoder 的物体读出。仍不能将 latent 数值解释为物理距离；两个测量渠道有不同语义。

## 3. 不能扩大的结论

- 本结论限制对**固定原生预测**的同一 state-only 后处理。FEEDBACK_CYCLE 改变后续历史与预测输入，不能直接以47.088约束整个新递推。
- 对 R(h,a,p;D)，输入含有可区别动作的额外信息，以上以 p 为唯一输入的下界不再直接适用。它也不保证使用这些信息就能成功。
- 非线性流形的最近点映射不总是全局非扩张；斜投影还可能具有大范数。不能把 L≤1 等同于所有几何修订。
- 当下真实编码可作为这次评价标签，但不能用于原查询的在线学习。该评估明确是 post-hoc oracle-labelled diagnostic。
- 47.088要求的是精确恢复这对 latent 目标，不是“任何有用改善都要放大47倍”，更不是将基座整体 Jacobian 乘47的算法建议。

## 4. 对继续建模的直接约束

只要求“让所有预测更近、更稳定、回到真实编码附近”是不完整的：当前困难同时需要消除某些错误变化，以及恢复被遗漏的动作作用。下一候选必须明确哪个输入或先验提供了两类变化的区别。原生动作和完整历史是合法信息，但如何从中推断正确响应仍需 Π 与 D 支持。

本轮斜投影审查给出另一项独立条件：已知应保留子空间 T 和应删除子空间 N 时，精确线性分离存在当且仅当 T∩N={0}，最小范数为 csc(theta_min)。这个条件不能补足 T/N 的语义识别，更不能从当前11帧 D 假定已经知道它们。见 [THEORY_SELECTIVITY.md](THEORY_SELECTIVITY.md)。
