# 应用数学重建探索：从稳定预测转向选择性修订

2026-09-27。研究形成阶段。未使用本地 skills；没有重新设计 backbone；没有改变主任务、旧原生算子、checkpoint 或旧结果。数学推导、文献核查与原生干预并行进行。

## 本轮裁定

**本轮尚未得到足以按 CVPR oral 主方法投入的机制；但已经把数学探索收窄到了一个有具体约束的候选：在动作和完整历史条件下，区分应该纠正的预测偏离与必须保留或恢复的动作作用，再将同一修订规则用于原生连续推演。**

关键改变是：不能把“更小的更新、更稳定的轨迹、更接近过去编码”直接当作正确修订的原则。当前原生失败包含动作后果的显著收缩；无区别地收缩预测可能与修复目标相冲突。几何约束值得继续作为候选研究，但“真实编码流形上的投影”尚不是已经找到的解法。

保留旧主问题：已经完成的视觉经历 D，如何改善尚未执行有序动作链 U 的后果和选择。保持所有候选共享同一 F_D，沿原生三帧 history/cache 自产反馈，不用额外分数头冒充动力学修订。

## 1. 真正展开了哪些数学重建

| 表述 | 已推到的可计算对象 | 本轮判断 |
|---|---|---|
| 共享因果核上的最小路径改变 | 路径 KL 链式分解；等协方差高斯下是访问分布加权残差平方；确定性路径直接用 KL 通常不成立 | 保留为校准原则/强参照，单独没有新的迁移机制 |

## 2. 实际跑了原生几何干预

固定 C(z)=E(decoder(z))，不调阻尼、不学习补偿、不用查询后果校准。对旧全部4案×8候选×5步比较：

1. FULL_REPLAY：原生完整历史重放；与旧 FULL 输出逐值相同。
2. READOUT_CYCLE：对已完成预测的 visual token 重编码，不反馈。
3. FEEDBACK_CYCLE：每个新 visual token 重编码后，进入同一个原生缓存；下一步仍调用同一 predictor。

**新执行320次 predictor 调用、200次 cycle 调用/408帧，0训练、0新环境步。** 预测先封存，再由独立评分进程读取未来结果。沿既有 `observation_transition` 扩展点执行，未新建世界模型或复制 rollout。

按 case 等权的结果：

| 指标 | 原生 FULL | 只改读出 | 回写 cycle |
|---|---:|---:|---:|
| 五步 visual MSE | 0.096004 | 0.106928 | **0.127261（恶化32.56%）** |
| 末端候选 latent 差分 MSE | 0.200050 | 0.209059 | **0.235258（恶化17.60%）** |
| 候选代价差 MAE | 0.215914 | 0.225992 | 0.237459（恶化9.98%） |
| 实际候选池 regret | 0.333378 | 0.332799 | 0.014929 |

不能隐藏最后一行的改善，也不能用它认证前几行没有证明的机制。FEEDBACK 在 T0、L1 选中真实最优，T1 变差，L0不变；四案 visual MSE 和 latent contrast MSE 都变差。这说明固定候选池中的选择改善可以与后果建模恶化同时出现。本轮既不能叫“修复成功”，也不能叫“所有指标都失败”。

## 3. 两种便捷的投影实现都没有得到依据

**现成 C 不满足理想 retraction 条件。** 在44张合法过去图像的编码上，C(z)−z 的 case 均值 RMS 为0.044–0.075；再次 cycle 仍改变0.027–0.053。它既不严格保持真实编码，也不幂等。量级与真实相邻编码变化可比，只能作尺度背景，不能当物理流形距离或人为设定的通过阈值。

**过去轨迹的 span 也不是全部合法动作方向。** 只用各案11帧 D 拟合仿射 span，L1 的28个原生末端差分只剩39.45%的平方能量，fact/g99只剩26.55%。这不证明被删成分就是正确信号；它证明“由D做正交投影自然保留动作区别”的假设不能成立。

还有一个直接的信息限制：11帧D是10Hz，但原生一步为0.5s。合法完整三帧原生 history 只有[0,5,10]一个，且D没有后续第15帧标签。不能把10Hz相邻三帧当作大量原生训练窗口。离线几何先验可以新增，但必须真实存在并向参照开放。

## 4. 得到一个与原生失败直接相关的数学限制

记 p_i,p_j 是固定原生预测，q_i,q_j 是真实编码。若同一个 state-only 修订 R 在这一点对的增益至多为 L，则

\[
\frac{\|R(p_i)-q_i\|^2+\|R(p_j)-q_j\|^2}{2}
\ge\frac14\bigl(\|q_i-q_j\|-L\|p_i-p_j\|\bigr)_+^2.
\]

使用 visual RMS 范数，L1 fact/g99 在最后一步的原生距离为 **0.023134**，真实距离为 **1.089350**。精确恢复这两个目标要求该后处理在此点对的增益至少 **47.09**；非扩张修订的点对平均末端 MSE 下界为 **0.284204**。

这是从实际封存 latent 得到的约束，独立于 decoder 轮廓读出。它解释了为什么“把预测拉近、压稳”不足以构成当前任务的解法原则。对4案×5时刻×28对全部计算，代码没有据此拟合新方法。

**范围必须严格：**这只约束固定 visual 预测上的共同后处理，不能约束带动作/完整历史的映射，也不能直接套到改变中间轨迹的反馈修订。47.09是精确恢复这对目标的必要增益，不是任何有用改善的必要倍率；下界仍允许部分改善。所有真值只用于本次追加评价。完整证明与结果见 [NATIVE_KERNEL_BOUND.md](NATIVE_KERNEL_BOUND.md)。

## 5. 下一候选可以怎样重新建模

优先保留的数学对象是**受动作与历史约束的修订规则**，作用在同一个原生转移上：

\[
p=f_0(h,a),\qquad
f_D(h,a)=\mathcal R_{\eta_D}(h,a,p;\Pi),\qquad
\eta_D=\mathcal I_\Pi(D).
\]

这只是接口。一个可以继续推导的具体优化形式是：由独立先验Π及D形成可计算的转移关系 C(h,a,z;η_D)，然后求

\[
f_D(h,a)=\arg\min_z\tfrac12\|z-p\|_W^2
\quad\text{s.t.}\quad C(h,a,z;\eta_D)=0.
\]

非线性约束下最优解可能不存在或不唯一，仍需建立局部可行性和选解规则；上式目前定义候选问题而非完整预测算法。给定这样的约束，在局部线性相容条件下，最小范数修正可由

\[
\delta z=-W^{-1}J_C^T(J_CW^{-1}J_C^T)^\dagger C(h,a,p;\eta_D)
\]

计算。需要 W 正定；需保证约束残差在 J_C 的可达范围内，或如实改为最小二乘近似。非线性时还需校验迭代后的实际约束与有限改动。所有候选共享同一η_D，每一步使用其自己的动作与自产历史；不能逐分支自由修改物性来降低目标代价。

**公式闭合不等于方法闭合。C 的合法来源是当前未解决的技术核心。** 若C就是z−f_theta(h,a)，这是另一预测器的变体；若C只检查图像逼真，无法识别错误但可见合理的交互；若C使用待执行动作的真实后果，就泄漏答案；若仅用F0自洽关系，可能保护F0原有错误。当前没有实现一个通过这些检查的C，因此本文件不把上述公式命名为新算法。

一个重要补充是应保留/应移除方向的关系。已知 T、N 时，精确线性投影存在 iff T∩N={0}；其最小范数为1/sin(theta_min)。这给候选可证伪的条件数，但**没有从短D识别T/N**。原生模型已经压扁的action span也不能当作正确T冻结。硬投影从identity连续降秩还与幂等性冲突；若做软修订，必须承认改变了约束。不能把这些经典结论当新贡献。

## 6. 新近邻使主张必须进一步收紧

数学近邻已有 [Otto等的斜投影与GAP/RVP](https://arxiv.org/html/2307.15288)，它明确以未来输出敏感度选择投影方向。其需要的可访问真实动力学/adjoint不能在我们这里无说明地用F0替代。

模型适配已有 [ReDRAW](https://arxiv.org/html/2504.02252) 的latent残差校准；多步自产训练已有 [SG-JEPA](https://arxiv.org/html/2609.10464)；解码训练分布问题已有 [RDR](https://arxiv.org/html/2608.25017)。这些必须是公平参照，而非描述成不存在。

追加检索还发现 [ACID](https://arxiv.org/html/2607.02403) 的inverse-action consistency，以及 [ActSWM](https://arxiv.org/abs/2607.26712) 摘要明确讨论的动作后果不可分辨。前者原方法将inverse残差加入规划代价；把梯度改为作用在预测状态上确实不同，但这个改动本身不足以承担主机制。后者本轮只到摘要层，不将其完整方法或局限视为已审计。

尤其不能以“动作可以被回推”当作交互正确的充分条件：若inverse模型只根据推杆位移就能恢复动作，物体后果仍可能任意错误。这与我们的自运动较准而物体响应明显失真的旧证据直接相关。用集合值inverse可避免强迫多对一动作有唯一逆，但仍需要D约束同一作用规律；并不会凭空解决正向响应辨识。

以上边界限制宽泛的新颖性表述，不证明我们的视觉经历修订问题已经解决。详细阅读范围见 [文献报告](PRIOR_ART.md) 和 [追加核查](PRIOR_ART_ADDENDUM.md)。

## 7. 继续投入的具体范围

本轮只保留一次“动作/历史条件下的选择性修订”形成投入，不扩大训练。下一段工作应让C或等价算子的**信息来源**变成可实现方案：明确哪些独立离线视觉轨迹/动作分支提供作用约束，哪些由在线D识别，并同时给普通原生residual/context、多步训练和inverse-consistency参照相同信息。

最有区分力的检验继续复用“自运动端点相近、内部作用路径不同、物体后果不同”的资产，避免inverse仅凭推杆完成任务；最终确认必须另采独立案例。必须允许并检查两类行为：真实动作应该产生不同后果时展开差别；不同动作实际等效时不人为拉开。最大化分支距离、每步独立选择可行物性、只降低预测能量，均不能替代这项要求。

若最终规则仍等价于普通residual fitting或已有verifier guidance，就如实保留为基线；如果C的构造需要知道查询答案，就关闭这一实现。方法和假说可以变化，旧主任务及其后果评价不变。
