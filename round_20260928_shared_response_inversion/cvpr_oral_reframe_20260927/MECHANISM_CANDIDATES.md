# 机制候选审查：观察到达后，行动后果为什么应该改变？

日期：2026-09-27。性质：有界理论审查；没有运行实验或编辑主模型。

## Target

在完整合法历史仍可使用的前提下，判断“新观察应修订哪些行动后果”能否产生一个值得主论文投入的独立计算机制。以下是本轮从问题推导出的候选审查，不是用新名词重述有限缓存遗忘。

结论先行：**目前有一个可计算、可否决的条件响应参照，没有一个已达到主方法立项门槛的机制。** 可计算性成立；视觉世界模型特有的结构理由和相对强普通方法的不同预测尚未成立。没有为凑数量保留第二个机制。

## Status

**COHERENT AFTER REFRAMING / EXTRA ASSUMPTION**，针对下述条件响应参照的数学表述。

**主方法贡献尚未建立；数学对象自洽。** 缺口是一个从合法视觉经历可识别、跨新行动仍成立、又没有被普通历史条件预测充分解释的共享结构。本文没有把这个缺口用“选择性”“因果”“一致性”等词隐藏。

数学工具已有先例并不自动否决一篇论文。这里不通过的原因是：当前候选除既有预测状态条件化之外，没有额外给出由视觉任务强制要求的对象、约束或计算规则；也没有证明一种有实际价值的学习、泛化或成本优势。

## Invariant Object

对象始终是合法历史下、指定未来行动的**条件预测**，不是当前帧的重构误差、latent 距离或历史插值误差。

令历史为 \(h_t=(o_{0:t},a_{0:t-1})\)。实际执行 \(a\) 后到达观察 \(O\)；从这个新时刻开始查询未来行动序列 \(b\) 的后果特征 \(Y_b\)。编码器及后果特征事先固定。所需对象为

\[
q^+(h_t,a,o,b)=\mathbb E[Y_b\mid h_t,\operatorname{do}(a),O=o,\operatorname{do}(b)].
\]

动作条件期望的干预含义不能由任意离线行为数据自动获得。以下形成实验使用随机执行且有覆盖的动作；实际项目若只有选择偏置的数据，应单独证明条件可识别，不能用动作拼接表示代替这一条件。

更新前参照为

\[
q^-(h_t,a,b)=\mathbb E[Y_b\mid h_t,\operatorname{do}(a),\operatorname{do}(b)].
\]

对所有 \(b\) 的正确条件化已包括“保留仍有效的旧证据”和“放弃被新证据推翻的旧判断”。两者不是天然互相冲突的数学目标；有限表示、有限数据、错误训练目标或错误接口可以使其冲突。

## Assumptions and Notation

1. 在线只使用真实已到达图像、已执行动作、合法可保留的模型状态和待查询动作。没有未来真值、物理隐藏状态、配对世界标识或真实观测 likelihood。
2. 训练使用完成轨迹中的未来图像作为监督是合法的；训练阶段使用未来图像，不等于在线查看未来。训练和评价轨迹严格分离。
3. \(E(o)\) 是实际模型可计算的编码，不预设为物理充分统计量。\(Y_b\) 可以是未来编码向量或固定任务读数；若使用编码平方误差，还需独立评价真实动作代价。
4. \(h\) 可以是完整图像历史。若候选实际只读取压缩 \(s(h)\)，必须把压缩造成的信息损失列入方法假设，不能把 full-history 方法强行限制到同一有损状态。
5. 所有期望、协方差的精确式是总体关系；实际神经网络或样本估计另标为近似。一个单独完成的 transition 不提供该历史下的真实条件协方差。
6. 局部视觉变化不等于局部预测影响。共同隐藏原因可以让一个小观察改变多项远期后果；“未在当前像素中变化”不保证某项预测应该保持。

## Derivation Strategy and Map

1. 先区分“前向预测输出不足以确定更新”与“完整世界模型不可能更新”。
2. 写出有限事件下的条件化恒等式，找到需要从真实经历学习的对象。
3. 给出可计算的线性参照以及非线性版本的精确退化关系。
4. 对照 PSR、HSE-PSR 和 PSIM，判断当前是否产生了独立结构。
5. 用强普通方法和一个小实验否决错误解释，而不是先开发复杂模块。

## Main Derivation

### 1. 一个严格但有限的 API 边界

**命题。** 仅给出证据到达前的逐时刻、逐行动边际均值，以及新观察，通常不能唯一确定观察后的条件均值。这里的“仅给出”是接口限制，不包括完整历史重推断、不包括联合预测分布，也不包括在额外数据上学成的条件更新器。

**构造。** 对环境参数 \(\sigma\in\{-1,+1\}\)，令 \(X\) 等概率取 \(\{-1,+1\}\)，新观察 \(O=X\)，未来动作 \(b\in\{-1,+1\}\) 的目标为

\[
Y_b=\sigma bX.
\]

两种环境都给出 \(\mathbb E[O]=0\)、\(\mathbb E[Y_{+1}]=\mathbb E[Y_{-1}]=0\)，各变量边际分布也相同。但观察 \(O=o\) 后，正确答案是

\[
\mathbb E[Y_b\mid O=o]=\sigma bo.
\]

所以相同的前向均值 API 输出与相同新观察，对应不同正确更新。一个只由该 API 决定、在两环境中完全相同的更新器不可能同时正确。两目标相反、幅值为 1 时，共同答案的平均 MSE 至少为 1。

**这个命题不是新原理，也不证明 JEPA 的 latent 必然不足。** 它只是边际量不确定联合关系的具体见证。以下四个边界必须一起保留：

- 若更新器另在真实轨迹上学到了 \(\sigma\)，其参数已经携带额外信息；上述不可能性不再适用。
- 若允许对新合法完整历史调用 \(F(h,a,o,b)\)，接口本身能够返回正确条件预测；“旧预测向量不充分”不约束这个调用。
- 某些 embedding 的均值可以确定所需分布；在条件确定的环境中也可能没有上述不确定性。不能从“使用 MSE”直接推出“条件更新不可能”。
- 它需要的是已执行 \(a\) 后、同一行动序列 \(a\to b\) 中 \((O,Y_b)\) 的联合关系。**不需要同时识别互斥未执行动作之间的 cross-world joint。** 把后者列成必要条件会人为扩大难题。

因此它适合说明一个具体 API 应补充什么信息，不足以独立承担主论文贡献。

### 2. 条件更新真正依赖什么

为免连续密度的技术问题，先令 \(O\) 取有限值。固定 \(h,a,b\)，令 \(I_o=\mathbf 1\{O=o\}\)，\(p_o=\Pr(O=o)>0\)，\(q^-=\mathbb E[Y_b]\)。以下都是恒等式：

\[
q^+=\frac{\mathbb E[Y_bI_o]}{p_o},
\qquad
q^+-q^-=\frac{\operatorname{Cov}(Y_b,I_o)}{p_o}.
\]

解释：应修改哪些后果，取决于证据与那些后果在当前历史和行动条件下的联合关系。仅知道该观察有多“意外”，并不能确定修订方向；仅保持变化较小，也不能保证正确。

这个式子也给出一个重要反例：若 \(\operatorname{Cov}(Y_b,I_o)=0\)，本次事件不改变该后果的条件均值；若它非零，即使图像变化很小，正确修订也可能很大。这里是特定事件与特定后果的条件关系，不能以无条件相关系数或空间邻近直接替代。

### 3. 唯一保留的可执行参照：学习证据到未来的条件响应

**候选地位：形成实验中的参照，暂不作为原创方法。**

可计算输入为 \(h,a,b,z=E(o)\) 及固定前向模型的预测。令 \(\mu_z(h,a)\)、\(\mu_y(h,a,b)\) 是数据拟合的条件均值。候选从完成的事实轨迹学习

\[
C_{yz}(h,a,b)=\mathbb E[(Y_b-\mu_y)(Z-\mu_z)^\top\mid h,a,b],
\]

\[
C_{zz}(h,a)=\mathbb E[(Z-\mu_z)(Z-\mu_z)^\top\mid h,a].
\]

线性响应为

\[
\widehat q^+=\mu_y+\widehat C_{yz}\widehat C_{zz}^{\dagger}(z-\mu_z).
\]

总体联合高斯、或者条件均值确实为该仿射形式时，这是精确条件均值；一般视觉分布下，它只是在给定历史条件下的最佳线性预测参照。协方差奇异时只在其可见支持上解释伪逆，不能声称支持外响应被识别。主机制未成立前不添加一套 ridge、clip、秩和信任区参数救结果。

**训练规则。** 在随机执行 \(a\) 和后续 \(b\) 的完成轨迹上计算实际 \(Z,Y_b\)；先以独立训练划分拟合均值，再以残差外积拟合协方差，或直接监督条件预测误差。若 history 连续、每个历史只出现一次，条件矩的估计必然依赖跨历史共享参数；这个共享结构正是尚待论证的假设，不能把统计符号当作免费 oracle。协方差参数化须保证 \(C_{zz}\) 半正定；简单小实验优先用有限分组的样本协方差，避免网络估计掩盖前提。

**在线规则。** 观察到达后只计算一次合法编码及响应；所有待选 \(b\) 调用同一已训练规则。下一时刻继续以实际历史或已定义的递归状态查询，不把一个更改过的读出向量无依据地塞回 frozen predictor 当合法状态。

**非线性推广。** 若写成

\[
s_{t+1}=U_\theta(s_t,a_t,E(o_{t+1})),\quad
\widehat Y_b=D_\theta(s_{t+1},b),
\]

并以真实未来图像特征监督 \(D_\theta\)，则计算上就是一个通过未来监督学习的预测状态滤波器。若 \(s\) 是任意 RNN 状态，不能在没有附加规则时把这个式子称作新的“选择性修订”。

**它相对简单融合的不同预测。** 常数增益或纯当前帧覆盖对同幅度证据使用相同修订规则；本参照可以因历史条件和行动 \(b\) 不同而反向或零响应。以上 \(\sigma\) 构造能显示这个区别。

**它相对强普通方法尚无不同预测。** 完整历史 Transformer、未来监督 GRU/RSSM 或直接学习 \(F(h,a,o,b)\) 都可以表达同一条件关系。没有证明它们遗漏了信息或无法学习该规则。当前候选最多提出“某个显式条件响应参数化会更省数据/更便宜”的经验假说；还没有给出其在视觉动态上成立的理由。

### 4. 为什么它暂时不具独立机制地位

三篇直接原始来源已足够定位当前构造，不需要用近邻数量堆出新颖性判断：

| 原始来源 | 已覆盖的对象 | 对当前候选的边界 |
|---|---|---|
| [Littman, Sutton, Singh, Predictive Representations of State](https://proceedings.neurips.cc/paper/2001/file/1e4d36177d71bbb3558e43af9577d70e-Paper.pdf)，§1、式(1)–(3) | 用行动条件未来事件预测表示状态，并用到达的动作/观察递归更新 | “直接更新未来预测、不先识别物理状态”已是明确先例 |
| [Boots, Gretton, Gordon, Hilbert Space Embeddings of Predictive State Representations](https://www.cs.cmu.edu/~ggordon/boots-gretton-gordon-HSE-PSRs.pdf)，§3.3–3.4、§4 | 可观测特征的条件算子、联合矩和 kernel Bayes 更新，包含连续行动/观察 | “学习 evidence–future 交叉算子避免真实 likelihood”不是新的原则 |
| [Sun et al., Learning to Filter with Predictive State Inference Machines](https://proceedings.mlr.press/v48/sun16.pdf)，§1、§3–4 | 原文设置为无控制输入的离散时间系统；从当前预测状态与新观察直接学习下一预测状态，以未来观察监督滤波 | 直接覆盖未来监督滤波的原则，不能单独据此认定行动条件版也已完整覆盖；动作条件算子的先例另见 PSR / HSE-PSR |

这不证明所有基于 PSR 的现代视觉方法都已做完。若能发现已训练视觉表示上的**具体条件闭包缺口**，并推导出在同等数据下确有必要的新特征/约束，仍可形成贡献；本文没有发现这种额外结构，也不把这个可能性写成已成立 idea。

### 5. 不复活旧的失败计算

已阅读旧项目的 `INNOVATION_DERIVATION.md`、`NEXT_PRINCIPLE_DECISION.md` 和 `SHARED_RESPONSE_HYPOTHESIS.md`。

- 旧线性 innovation 用 \(p_D-p_0\) 预测视觉 residual，已有 READOUT 迁移失败及 FEEDBACK 进一步恶化的裁定。
- 旧 multisecant 假设跨动作共享同一线性增量作用；精确历史插值没有兑现新动作价值。
- 本文的条件矩对象与那两个对象不同，但**仅把输入换成视觉 innovation，再拟合一个矩阵，不构成新的理由**。它仍需真实的跨历史、跨行动条件关系；不能把此前失败算作这里的正面动机。
- 当前没有必要重新运行旧映射、改变 ridge/clip、增加秩或换一个 updater 名称。

## Minimal Falsification Experiment

这个实验决定是否值得继续机制形成，不是独立新论文验证。若主流程已安排了更严格、等信息的同类小实验，应复用，不再新建平行 operator。

### A. 先把最容易包装成贡献的解释击穿

将上述 \(X,\sigma,Y_b\) 构造成可枚举小数据集，\(X\) 及后果以简单图像位置显示。训练轨迹随机执行 \(b\)；每条训练轨迹只交付其实际执行后果。\(\sigma\) 不在线作为隐藏标签输入：可以固定不同训练环境，或通过合法历史校准片段被识别。

比较前向均值＋当前观察的无额外信息接口、样本条件响应、完整合法历史直接回归、未来监督 GRU。给后两者同样训练轨迹、同样可见历史和至少等量可训练参数。

预期结果是后面三者都能学会。如果仅均值接口失败，这只确认经典信息边界，应停止把这一见证扩大为核心创新。若条件响应优势只来自给了它 \(\sigma\)、更长校准历史或额外 pair 真值，结果无效。

### B. 真正决定方向的最小视觉任务

在现有小型图像运动主路径上加入**有效但局部的新证据**，并明确保持旧的运动信息何时仍有效。最低配置是一维位置/速度、两个后续加速度动作；模型只看到图像和动作。

固定四类预先生成的测试段，不能按训练后结果挑选：

1. 只改变独立背景纹理，物体动力学不变；后果预测应保持。
2. 新帧揭示位置已变化，后续轨迹需从新位置开始；此前速度仍有效。
3. 连续两帧给出足以识别的新速度，旧速度应被放弃。**单帧不能辨别速度变化时不得要求模型猜中隐藏变化。**
4. 同一证据后的两种后续动作产生不同目标代价；同时评价后果和行动排序。

场景需有可视化检查，确认任务无法靠忽略观察、只用最新帧或泄漏事件标签解决。隐藏位置/速度只用于生成与独立评价，不进入训练 updater 输入；未来图像监督对所有学习方法相同。

强基线至少包括当前 native path、完整历史重推断、持久 GRU/RSSM、普通 learned fusion，以及同数据的显式条件响应。训练预算与可用信息分开对齐并报告；若某个基线尚未学好无更新任务，不能用它判定结构缺陷。

最低读数：更新后短/长时域真实后果误差、相关/无关证据分别的响应误差、两个动作的代价差误差与真实 regret。不得只用“不忘”“latent 不坍缩”或观察重构改进判胜。

### 事前否决线

- full-history 或持久状态在合理成本下同时解决四类情况，而显式条件响应没有额外可复现优势：**否决当前候选的主方法地位**，将现象归为表示/接口或训练修复。
- 显式响应只在预设线性生成器上获益，改为同信息的非线性关系后失效：支持线性归纳偏置，不能宣布普适视觉更新机制。
- 获益仅来自额外未来标签、隐藏变量、不同历史权限或更多训练：否决该比较。
- 增加历史容量或普通混合反馈训练已经解释收益：否决“需要新的 evidence propagation 原理”的解释。
- 显式响应稳定超过强普通方法仍不是终点：只有当条件关系的测量与控制干预能解释优势，才考虑进入原生视觉基座验证；不得事后仅凭分数发明机制。

不在这里任意指定百分比成功阈值。实际合同应按可复现实验噪声、最小有用 regret 改善和资源预算事前冻结；先看全体种子与各情况，再作置信区间和效应大小解释。

## Remarks and Interpretation

当前最值得带回主立项文档的不是一个新模块，而是更准确的研究区分：

> “记住历史”保证证据没有被删；“从证据修订行动后果”还需要学到正确的条件关系。完整历史学习器原则上可以同时实现二者；新机制必须说明自己额外提供了什么。

这个区分比“JEPA 应该加入 belief”精确，但精确描述问题仍不等于完成创新。现有材料已支持有限状态碰撞，尚未支持在完整合法历史与合理普通滤波允许时存在独立剩余瓶颈。

## Boundaries and Non-Claims

- 没有证明官方预训练 JEPA 普遍缺少联合信息。
- 没有证明 Bayesian filtering、PSR 或 RNN 已经充分解决所有真实视觉任务。
- 没有要求首次发明一种基础数学工具；要求的是具体任务迫使我们采用什么新的计算，并由何种证据识别它。
- 没有把 action-conditioned prediction 自动称为因果发现或反事实识别。
- 没有认为常规方法理论上能表达答案就足以否决任何经验贡献；实际数据效率、泛化和计算优势仍可成立，但尚需被提出和证明。
- 没有新增第二个候选来填满配额，没有启动参数更新、学生替换或新 operator 版本。

## Open Risks

1. 正确更新依赖的相关性可能不在 frozen visual encoding 中；若丢失的是原始图像信息，需要先测量表示缺口。
2. 不同历史下条件响应可能高度不共享；样本条件矩将很难估计，不能默认比 full-history 回归更易学。
3. 实际离线数据可能缺少待查询行动覆盖；没有覆盖时，一个更复杂滤波器不会凭空识别响应。
4. 若所有小任务强基线都解决，仍可研究真实视觉长时程的工程问题，但当前“核心机制”版本必须关闭。
5. 若认为这里过于保守，需要补的不是更宏大的动机，而是一个允许输入可识别、强普通方法尚未解释的新关系及可区别预测。

## 本轮裁定

**保留问题，保留一个经典且可执行的条件响应参照，零个主论文机制通过。** 下一份主立项报告不应写“已选定新机制”。若选择继续，应该明确下一项工作是在寻找或否决额外的视觉结构，而不是已进入方法实现与规模扩张。
