# 有限真值表数学验证

2026-09-27。结论：**PASS；该构造只支持经典的受限信息接口边界，没有形成新方法优势。**

运行命令（PowerShell；Python 3.11.5，仅标准库）：

```powershell
python '<RUNS_ROOT>/cvpr_oral_reframe_20260927/math_probe.py' --output '<RUNS_ROOT>/cvpr_oral_reframe_20260927/MATH_PROBE.json' 2>&1 | Tee-Object -FilePath '<RUNS_ROOT>/cvpr_oral_reframe_20260927/math_probe.log'
```

模型为 `X∈{-1,+1}` 均匀，`O=X`，`b∈{-1,+1}`，`Y=σbX`。两个环境分别固定 `σ=-1` 和 `σ=+1`。每个环境枚举同样的四个 `(O,b)` 支持点；每条训练记录只包含实际执行的 `(O,b,Y)`。

| 检查 | 精确结果 |
|---|---|
| 两环境的观察边际、各动作未来边际及均值 | 完全相同；均值全部为 0 |
| 给定相同 `O,b` 的后果条件均值 | 两环境符号相反，幅值均为 1 |
| 任意共同 API 答案 `p` 的跨环境 MSE | 恰为 `p²+1`，下界 1，由 `p=0` 达到 |
| 有限事件更新 `E[Y|O=o]−E[Y]=Cov(Y,1{O=o})/P(O=o)` | 8 个逐环境/逐动作/逐观察检查均残差 0 |
| 同样事实训练样本的条件频率、普通条件均值 OLS、协方差参照 | 24 个预测检查全部正确；各环境、各方法 MSE 均为 0 |

所有代数与统计计算使用 `fractions.Fraction` 精确有理数。下界不是由若干数值点推断：程序从两个目标直接验证风险多项式的系数恰为 `(1,0,1)`，另列七个预测值作为数值见证。

普通回归使用固定可观测特征 `φ(O,b)=Ob`，最小二乘系数从事实样本计算。条件频率直接统计 `P(Y|O,b)`；协方差参照从相同数据计算分动作均值与协方差。三种方法的在线 `predict` 均只接收 `O,b`，不接收 `σ`、未观察状态或未来真值。

每个环境独立训练；拟合后的系数可以储存从经历学到的环境信息。因此它们拥有受限“前向边际均值 API”之外的信息，成功不会反驳该 API 的不可辨识命题。该实验也说明，没有理由把这个构造中的成功独占地归给显式交叉响应。

这是对同一有限支持集的完全枚举，训练与评价支持重合；不是独立测试集泛化实验。没有图像模型、神经网络训练、官方 checkpoint 或现实强基线实测，不能据此声称完整历史模型或 GRU 已解决真实视觉问题。没有引入第二候选或修改主 operator。
