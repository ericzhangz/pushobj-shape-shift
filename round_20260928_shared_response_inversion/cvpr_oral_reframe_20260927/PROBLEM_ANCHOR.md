# 本轮问题与机制共同立项合同

2026-09-27。来源：用户明确要求以 CVPR oral 为最终目标，并授权执行上一轮完整计划。当前 goal active。

## 固定研究目标

寻找视觉动作条件世界模型在持续吸收真实证据、修订未来行动后果时的重要能力缺口，并形成一个有独立机制价值、可计算、可被最小实验否决的研究方向。当前硬回写失效是已有限定的证据资产，不预设为论文主线。只有在合理的历史保留、训练与常规融合对照之后仍有实际价值，候选才可推荐进一步投入。

## 不变量与信息权限

- 历史结果、失败阶段、固定阈值与原主路径保留；不追溯重判。
- 模型运行状态、模型参数变化、观察编码与预测状态的作用分开；不得混为一项因果证据。
- 预测/更新只能使用已到达观察、已执行动作及合法预训练资产；未来后果、物理真值、成对反事实身份只用于封存后的评价或明确标记的离线诊断。
- 允许正常或适度增加计算；不预设冻结、training-free、低成本、GRU/记忆/生成元/特定数学域。
- 新代码若进入原生模型实验，复用当前主路径，不创建新operator版本或并行deployment实现。
- 不能通过禁用强基线、限制可得历史、删除失败seed、放宽门槛或无限追加训练来保住候选。

## 本轮交付

1. 一手近邻的机制/信息/训练边界矩阵与实际资产核查。
2. 至多两个机制性候选；每个给出明确数学对象、可实现规则、适用假设、最强普通解释及差异预测。
3. 在读取新评价结果前固定最小决定性实验、资源与裁定，实际执行必要且可行的验证；若某候选在理论或近邻门已被否决，不为它训练新架构。
4. 独立审查后的统一立项论证、完整结果与停止理由。最终最多推荐一个方向，也允许全部不达标。CVPR oral 是研究标准，不是本轮可保证的录用结果。

## 工作顺序及验收

1. 原文/代码核查 → 验证：每项机制判断有一手来源，资产能力与未验证项清楚。
2. 问题—机制推导 → 验证：候选不是已知方法改名，且有不同于强普通基线的可检验预测。
3. 实验前合同与实施 → 验证：信息对等、实际执行、失败保留，禁止评价真值进入拟合或选参。
4. 独立质疑与最终裁定 → 验证：结论不超过来源和实测范围，给出继续或停止的明确依据。
