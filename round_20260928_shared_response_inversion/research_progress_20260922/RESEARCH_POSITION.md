## 2. 从 ChordEdit 借鉴什么

真正值得借鉴的是：可观察的失败 → 明确的数学对象 → 带假设的代理问题 → 简单计算规则 → 与该规则对应的证明和对照。其原文从动态 OT 视角走到加权平均，中间引入了观测噪声假设、局部二次代理及一阶近似；并非从一个宏大理论无条件推出唯一算法。[原论文 §3–4、附录B](https://arxiv.org/html/2602.19083v1)

所以我们不寻找“自己的 Jensen”来补装饰，也不规定自己的 organizing principle 必须叫能量。需要先明确：**什么量刻画了合法经历对新动作预测修订的约束，以及为什么控制它会有用。**

还有一个值得保留的研究习惯：简单替代解释必须正面对照。一项独立复现预印本发现，改变单个查询时刻的简化版本可接近 ChordEdit 默认设置的表现；这不是定论，也未否定整篇论文，但说明理论叙述漂亮不等于机制贡献已经被隔离。[复现实验 §4](https://arxiv.org/html/2606.14042v1)

## 3. 本轮只补了一个交叉重放，不重启诊断阶段

G3 原来的“早期好、后期差”同时变化了处理器与查询。现将四步剂量已保存的 P2/P4 分别作用于同一 case 的 Q2/Q4：只补缺失的两格，另两格及 Frozen 复用原预测。

下表为相对各自查询 Frozen 的误差降低比例，**正数改善**；先平均 case 内两 seed，再对六 case 等权。

| 已保存处理器 | Q2：S5 / D5 降低 | Q4：S5 / D5 降低 |
|---|---:|---:|
| P2：前两份经历后 | 18.31% / 38.51% | 0.0415% / 0.4795% |
| P4：前四份经历后 | 13.39% / 30.92% | −3.889% / −0.0487% |

结论只到这里：

- P4 在 Q2 上仍保留大部分平均增益，不能把原先跨时点现象全部归为遗忘。Q2 的 D 改善高度集中在 L1；P2 的净绝对 D 改善约99.26%来自它，不能讲成普遍早期有效。
- P2 放到 Q4 也几乎没有平均增益，单纯保存早期 P 不足以恢复早期表现；不等于 Q4 在整个函数类内不可处理。
- 固定 Q 后，P4 相对 P2 的平均结果变差，但 case 方向混合。它隔离了这两个处理器变化的作用，未隔离额外事实、更新次数及优化路径各自的原因。

### 有限修正的方向与大小不能混为一谈

令 r=真实后果−Frozen预测，δ=处理后预测−Frozen预测，则精确有

\[
\Delta S=\operatorname{mean}_q\left[\tfrac12\|\delta_q\|_W^2-\langle r_q,\delta_q\rangle_W\right].
\]

D 使用 r、δ 的候选两两差，形式相同。P4/Q4 的 S 中，平方项为0.00068947，对齐项为−0.00012718，净变化为+0.00081665。**实际学到的修正不仅没有足够对齐，平均对齐还为负。** 但这不能证明其他允许修正也无效，更不能由此倡导“最小能量”：δ=0的平方项最小，却不修复任何错误。

这组有限数据约束下一步建模，不充当“信息不足”“表达不足”或“优化错误”的唯一原因证明。

## 4. 我建议推进的数学问题

**在共享近共轭允许的修正空间中，研究“经历约束下的新动作后果稳定恢复”。**

这是对当前 mathematical domain 的细化，不是换到 Bellman／OT 等另一套路线。组织性原则是：

> 不要求经历唯一确定整个 P；要求经历尚不能区分的允许修正，不会导致不可控的新动作后果分歧。

用真实 history 上的同调作用定义经验算子 A，用完整新动作 rollout 定义查询算子 B。前者描述一项修正在已发生经历上如何显现，后者描述同一项修正在未来动作链上如何显现。基础关系为

\[
\ker A\subseteq\ker B,
\qquad
\|Bd\|\le\kappa\|Ad\|.
\]

第一式是“事实等价是否推出查询等价”；第二式是“近似事实等价是否也能稳定传递”。它们不是新的机器学习算法，也不是 G3 已经满足的条件。完整定义、证明、受限类和非线性余项在 `MATHEMATICAL_BRIDGE.md`。

这一步比旧同调公式多了什么？旧公式规定**可表达的修正**；新问题要求**经验能够稳定决定的查询作用**。但这一想法在上一份 G3 说明中已有自然语言提示，本轮是把它精确化，不能自称发现全新原理。

必须同时保留两个 B：绝对后果与候选差分。共同偏差对差分可能不可见，但仍改变 S 和任务投影。更重要的是，所有可行 P 也可能一致地预测错误；因此“歧义小”必须与“所需修正在允许类中可表达”分开。

## 5. 后续安排：先推导，不再扩充 G3

1. **把上述问题落到当前主路径。** A 必须采用原 factual sliding windows 的真实权重与历史槽；B 必须采用原5步、最多3槽的 native rollout。只做必要的局部导数／有限差分一致性验证，检查 near-identity 近似是否覆盖当前修正尺度；不重新审查 G0/G1，不创建新 operator。
2. **推导一次真正有内容的经历写入规则。** 目标是在保留共享、精确逆和边界执行的同时，说明新经历增加了哪些查询相关约束，以及如何有效保留它们。允许正常或适度增加的计算开销；额外展开、Jacobian或矩阵运算应按实际规模评估，不因其名称或增加调用而提前排除，也不默认其可部署。实验前说明计算量，避免夸张增长。
3. **区分现有算法与新增内容后才做下一轮学习。** 若所得只是最小二乘、伪逆、通用正则或投影梯度，作为基线而非主创新。与同函数类普通拟合、output-only、同时间普通更新，以及适用的多步／Hallucinated Replay 控制比较。不能因为新规则换了名字就自动重跑更大实验。

一个可检验的积累原则：在误差容差和允许类不变、约束相容时，新经历应缩小“与事实相容的修正集合”；有价值的部分是它是否进一步缩小了查询后果分歧。**集合缩小本身不保证选择出的点更准确，更不保证固定存储能精确保留所有约束。** 这正是规则与证明需要解决的内容，不是已经实现的持续学习方法。

本轮不声称已找到底层机制。阶段性产物是一个可证伪的第二阶段数学问题及其必要证明框架；**“处理器类＋Adam”停止作为当前主候选，processing 数学域保留。** 若不能从这个问题推出比同类普通拟合更有内容、可实现且开销合理的规则，就如实保留机制空缺，不用模块叠加填满链路；不要求其必须比原过程更便宜或几乎零额外开销。
