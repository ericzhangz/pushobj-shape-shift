# 动作轨迹库的必要支持审计

2026-09-27。只运行 CPU 线性代数；没有拟合物体响应、读取 query evaluation targets、训练、模型调用或新环境交互。当前四案只读查询前两 chunks 的动作；从封存 `interaction_validation_20260927/native/PREDICTIONS.pt` 提取32个候选动作，未使用其中的 goal、latent 或解码结果。

## 窗口和矩阵定义

离线库取 T/L sample2..11 的20条已完成经历。在每条 episode 的5个 stride-5 相位中分别取3个历史观测和 H 个未来转移，H∈{1,2,3,5}。若第一历史观测的低层帧号为 s，则历史观测为 s,s+5,s+10，未来最后一帧为 s+10+5H，动作列由该区间的2+H个10维 packed actions依时序展平。

从不跨 episode 或跨相位连接时间；列之间可以来自不同 episode，但它们只是不同轨迹实例。完整列元数据包括 episode、phase、起始帧、当前anchor帧和最后未来帧，保存在 BEHAVIOR_SUPPORT.json（历史本地产物，未纳入本次上传）。

每列动作维度 d=10(2+H)。使用原档案 `normalized_model_actions` 原值，转float64后计算，没有白化、重新归一化、拟合或补时长。“raw packed”在此指未经此次处理的模型动作坐标，不是反归一化的环境控制量。

同时计算 A 与 [A;1ᵀ] 的奇异谱和数值秩；阈值固定为机器精度×max(行数,列数)×最大奇异值，不按结果选秩。

## 对下一步建模的含义

1. **H1/H2动作满秩不是动力学已被覆盖。** 无限制的实系数可以表示任意同维动作向量；必须再检查对应输出、初始历史、系统参数与可能模式是否能由同一个g合法表达。没有输出和过去状态约束，动作投影为零可以是纯维数现象。
2. **H3的现成库连全部已封存动作都无法精确表示；H5无完整库。** 若采用硬动作等式的此窗口行为约束，H3当前查询不可行，H5不能形成该约束。添加正则项不会增加张成空间；缩短窗口并逐段滚动会改变所需论证与误差传播问题。
3. 这些秩只涉及既定长度的输入堆叠，没有已知系统阶数，更没有检查经典持久激励所需的更高阶 Hankel 条件。不能从 full row rank 宣称符合 fundamental lemma、受控系统线性、物体响应线性，或行为库能生成正确后果。
4. 两shape池提升action-only覆盖并不证明两shape共享同一个输入输出行为。使用更丰富库时，响应条件或适当系统同一性仍必须另外建立。
5. 所有动作来自有限的旧闭环执行，数量和数值秩不能替代几何/接触覆盖分析。此处没有以未来物体状态选择子库或配权。

当前结果允许继续考虑短窗口的合法数据约束，但不支持直接把现有20条短轨迹当成完整5步规划后果的精确行为库。不能以人为截断或跨episode拼接掩盖这一支持缺口。
