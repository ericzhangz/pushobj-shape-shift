# 物体响应约束：四篇近邻的方法级边界

2026-09-27。范围限定为“自运动可以较好预测时，如何从已完成经历获得物体响应关系，并用于另一动作路径”。未使用本地 skills，未运行实验，未改旧文件。先读本仓库上一轮 `REPORT.md`、`PRIOR_ART_ADDENDUM.md` 及旧 `INNOVATION_PRIOR_BOUNDARY.md`；以下四项均核对原始论文的方法段，非摘要层新颖性认证。

## 当前判断

**“先处理自运动、再学习物体响应”已经有直接覆盖；“从交互历史提取物性/动态 context”也已有成熟实现。仍可探索的是一个具体的求解对象变化：D 不只是产生下一状态补偿，而是限定跨时刻、跨动作共享的响应关系；这个关系必须能从合法信息计算，并能沿原生路径生效。** 经典数学不构成否决理由，但共享关系必须产生可检验、不同于任意残差拟合的约束。

还有一个范围限定：目前“自运动较准”只是旧案例的观测。接触可能反过来改变机器人实际运动，因此“在所有场景中强制保持 nominal 自运动”并非普遍物理不变量。

## 四篇原文

### 1. Robot-Factored World Models via Robot Rendering（2026）

实读 §3.1–3.5。方法先用部署可用的 controller/kinematics 得到 nominal robot trajectory，再渲染机器人几何，与场景 RGB/depth 一起条件化视频模型。模型负责 nominal 与 realized 的交互差及物体变化。训练使用视频生成目标，未在这些方法段给出由短 D 辨识共享接触规律的在线更新。[论文](https://arxiv.org/html/2607.22535v1)

**对本任务的边界判断：**分解本身、把动作换成可见机器人运动、减少自运动学习负担，不能作为我们的独立贡献。该分解也不能为“query 的真实未来机器人位置可用”背书。它留下的具体问题是：给定部署可计算的作用路径，某次新经历到底修订了哪一个场景响应关系。

### 2. COCOI: Contact-aware Online Context Inference（IROS 2021）

实读 §V 和 Fig.3–4。将历史前后图像与腕部力读数编码为 context，多个样本平均后送入 Q 网络；根据接触力选择有信息的经历。它主要适配动作选择，不输出共享世界模型转移约束。[论文 §V](https://arxiv.org/pdf/2011.11270)

**边界判断：**“只从发生作用的经历推断物体属性”并非新思想。我们的视觉 D 没有同等力标签，视觉接近也不自动等于有效接触。若新方案仅为历史编码器加对象 mask/context，应按普通条件适配评估，不能因写成 C(h,a,z)=0 就视为新机制。

### 3. Phys2Real（ICRA 2026；arXiv 2025）

实读 §III-B/C。物理参数条件策略在仿真训练；适配 ensemble 从历史状态—动作估计可解释物性及不确定性，再与 VLM 先验做方差加权融合。论文明确讨论没有信息的交互历史；其推物体实验关注质心。目标是策略适配，并非冻结 latent predictor 的路径修订。[论文](https://arxiv.org/html/2510.11689v2)

**边界判断：**D→共享物性→未来行为这条大链已有直接近邻，不能把“所有候选共享一个物性”独占为创新。它同时给出了合理信息模式：离线多物性环境提供辨识先验，在线 D 缩小可能性。我们如需额外离线数据，应明确提供，而不能假装短 D 独自辨识全部关系。

### 4. ContactNets（CoRL 2020 / PMLR 2021）

实读 §2、§4.1–4.2、附录 A.1。它学习距离函数、接触 Jacobian 与摩擦参数化，并由求解器产生非光滑转移。训练时假设惯性与非接触动力学已知，从真实速度变化求净接触冲量；未测的各接触冲量由内层凸问题解释，同时惩罚互补、穿透和耗散条件违背。[论文](https://proceedings.mlr.press/v155/pfrommer21a/pfrommer21a.pdf)

**边界判断：**这是最贴近用户所说“改变数学求解对象”的参照：共享未知量是生成作用的关系，输出跳变由求解过程产生。这种思路可以借鉴，但物理状态、惯性和非接触模型在我们的 global visual latent 中尚未给出。把 ContactNets 接到模型上，或把其物理约束改名，也不能自动形成新贡献。

## 对本任务的建模推论（以下为本轮分析，不是四篇论文的原结论）

### 自运动约束与响应约束分别携带什么信息

如果状态写为 (p,x)，逆动作约束只读取 p′−p，那么 p′ 正确时它不会限制 x′。对象 mask 只是把评价/更新集中到 x；它仍没有告诉我们 x 应怎样运动。把 mask、action quotient 或 robot factorization 当成 C 的全部来源，会遗漏作用规律本身。

由已完成经历得来的普通残差 e_D，只说明某条已执行转移错了多少。若要跨动作转移，必须另说明误差怎样随作用点、相对运动、对象状态和作用时间改变。不存在从“物体错了、推杆对了”直接推出某种几何或能量模型的唯一逻辑；可以提出候选关系并用数据筛选。

一个合理的重建范式是学习共享的**隐作用解释**：某条物体运动必须能由当前作用几何下的允许作用量生成；同一关系同时解释 D 和候选推演。作用量可以是物理冲量，也可以是经过独立校准的作用坐标，但两者不可混称。若称物理能量或摩擦，就必须提供单位、度量、力/速度对应关系；visual latent 的欧氏范数不会自动具备这些意义。

### 什么数据能够支持超出普通残差的共享响应

| 合法信息 | 能支持的关系 | 不能直接支持的结论 |
|---|---|---|
| 当前 D 的连续对象/作用端运动及可信对应 | 已访问位置、方向、时间尺度附近的局部响应 | 未访问接触方向、速度、作用点上的唯一规律 |
| 不同作用点、方向、速度的离线对象交互轨迹 | 共享关系先验；D 在此先验中的辨识 | 把离线先验当成由短 D 自发发现 |
| 已知或独立估计的惯性、非接触运动、几何 | 净作用量与接触约束的物理解释 | 凭 RGB/global token 直接知道全部物理量 |
| 多条已完成且有明确时间戳的 legal D | 检查同一参数能否解释重复/组合经历 | 用未执行 query 后果拟合这些参数 |

当前 D 是 10 Hz，原生 predictor 宏步为 0.5 s。细时间采样可用于单独的视觉响应辨识，但不能伪装成多个完整原生三帧监督窗口。若做子步关系再组合到宏步，组合假设本身必须检验。

一个最小辨识检查可以用线性关系 y=Kξ 表达：D 只约束 K 在已激励输入 span 上的作用。即使拟合 D 无误，也不能据此保证未访问方向；参数正定或能量最小只提供额外归纳偏置，不会凭空补出真实标签。这不要求最终方法线性，只要求它如实展示 D 消除了哪些解、仍留下哪些解。

### 对 energy / proximal 迁移的具体要求

如果假设某种响应由凸势的导数或 proximal 算子生成，就得到单调性、积分一致性等实质约束。它们有价值，因为能被经验反驳；不能只留下“最小能量”这个名称。带接触切换、滑移、旋转与历史效应的有效宏步关系未必满足单一凸势，尤其不能把物体能量下降当成外力驱动交互的普遍规律。

建议在当前小规模形成实验中明确区分：

1. 结构本身是否与合法 D 相容，是否需要未提供的状态/传感信息。
2. 共享关系在未参与估计的作用方向上给出的预测是否正确。
3. 把约束作用于原生 token 后，物体后果是否改变且自运动是否仍准确。
4. 同样的对象读出、历史和离线先验交给普通 residual/context/物理辨识时，新增数学规则是否仍有收益。

“已知自运动后只修订对象”适合作为实验控制和机制定位，尚不能承担新主张。更有区分力的成功证据是：同一个从 D 得到的关系，在另一动作路径中依据新的作用几何生成正确响应，同时对真实等效动作不制造假差别。这个目标尚未被本次四篇边界核查证实实现，也没有因数学经典而被否决。
