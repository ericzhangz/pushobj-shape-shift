# 独立范围复核：撤回“主线 energy plot 已冻结”的定位

2026-09-28。仅复核既有报告、预注册文档和审计；没有使用本地 skills、没有启动新实验。ChordEdit 原文的具体建模及证明链由主代理另行核验，本文不代其作论文事实判断。

**用户批评成立。实验回答了一个合法但局部的经典原型比较问题；我们把它放到了“主任务的建模桥梁已经冻结”的位置。应撤回这一定位，而非只给旧图更名后继续沿用其研究地位。**

## 层级混淆在哪里

| 层级 | 当前材料实际支持的内容 | 不应被替代成什么 |
|---|---|---|
| 主任务 | 重新建模视觉世界模型的状态演化与计算，使连续动作推演产生有效的交互后果 | “谱响应状态能否赢 GRU” |
| 经验失败 | 旧 L1 的若干动作后果严重压缩；新池原生预测较好 | 世界模型普遍塌缩，或新小模型的泛化困难 |
| 数学对象 | 响应表、实现状态、移位算子是一种已知的候选对象 | 已被失败证据必然指定的唯一对象 |
| 诊断量 | 真实差分模长、预测沿真值方向的投影、正交误差 | 由对象和约束推导出的能量泛函或求解原则 |
| 候选算法 | SVD、共享仿射矩阵、历史初始化及其经典对照 | 我们已经确立的核心机制 |
| 比较结果 | 当前谱原型未显示跨动作预测优势 | 数学重建已失败，或必须先赢基线才允许继续建模 |
| 冻结 | 本次已执行实验的输入、代码、判据、结果应不可事后改写 | 主论文对象、核心矛盾、关键图均已成立 |

最具体的错误在 `FROZEN_QUESTION_AND_PLOT.md` 的“主问题”：它将标准谱原型与普通训练的比较升级为整个任务。`REPORT.md` 虽反复声明图不是物理能量，仍把“可以冻结坐标”作为本轮核心交付；该谨慎措辞没有补上从原生失败到数学问题的联系。横轴依赖未来真值本身并非错误——离线诊断当然可以读取真值——缺少的是该量为何决定我们应重建什么计算，而不只是描述输出误差。

## 谱结果现在排除了什么

当前有限秩、合法历史初始化、冻结视觉读出和已记录训练预算下的谱实现，没有达到晋升主机制的证据标准。其全路径及候选差分不优于同信息常规对照，且所有从头拟合的小模型远弱于原生。二步测试误差已经很大，因此这批结果不能单独定位“未见长动作组合”的困难：初始化、读出、低维模型类、数据量和短程泛化仍混在其中。

它没有排除响应作为状态定义的数学价值、非谱实现、其他动力学重建或利用原有预训练能力的计算重建，也没有解释旧 L1 原生错误的原因。新池原生成功同时否定了“这套新池天然呈现原生分支塌缩”的预期。不能把其中较弱模型的困难改写为我们的新动机。

实验并非白做：它阻止了把一个经典可写出公式的原型误当作已成立的研究解法。但是现在应当**归档为被否定优势主张的探索记录**；不继续承担“energy plot”、主机制或必经实验门槛。

## 应怎样恢复研究顺序

保留宽而具体的任务和真实正反证据；撤回对响应实现、当前散点图及其方法比较问题的主线冻结。下一阶段的中心工作是让同一条解释把“原生计算何时失效、什么数学对象应被求解、哪些可获得约束定义该问题”连起来。分析与小规模检验可以相互修正，不需等唯一根因全部定位，也不需先证明某经典原型胜过 GRU 才开始数学重建。

只有当候选对象和约束产生一个有内容的计算矛盾时，才有理由确定用于展示该矛盾的关键量及关键图；再讨论可计算近似、求解规则和方法比较。这个顺序不是机械的线性流水线，更不要求照搬某篇论文的数学工具或写作顺序。现阶段缺的是建模联系，不能靠更换图名、追加基线或继续修补谱模型替代。

已有实验合同仍作为历史协议保存，不改写、不删除；研究主线的冻结状态应明确标记为撤回。谱表及图片以后若有具体分析用途可以复用，不能为了保留投入而预先占据新主线的位置。
