# ChordEdit 成文链路核查

2026-09-27。依据 [arXiv v2](https://arxiv.org/html/2602.19083v2) 的 §3–4、附录 B/C/D/E/K，以及此前保存的[独立核查](../research_synthesis_20260927/CHORDEDIT_LOGIC.md)。未使用本地 skills，未执行外部模型。本文只核对论文呈现的论证，不推定作者产生灵感的先后顺序。

## 可直接放入汇总的链路

**应用接口失效 → 重设未知量 → 规定全局目标 → 建立可观测代理 → 加入局部统计假设 → 求解局部子问题 → 两点近似 → 一次更新与可选清理 → 分别检验机制与编辑结果。**

论文关注一步生成器上免训练、免反演的文本编辑：直接对条件场作差并进行大步更新，会损坏物体和背景。它把未知量改为完整编辑控制场，以动态输运的动能目标组织问题，再把条件差当作其可查询代理。局部可观测、近似常值和递归先验三项假设产生二次估计；两点近似使之可计算。算法保留原骨干，以一次输运更新和可选目标条件清理生成结果。机制验证与图像指标、噪声及清理消融共同构成证据。来源：[§1、§3–6、附录 B/K](https://arxiv.org/html/2602.19083v2)。

## 精确公式与符号索引

以下公式供主文件选择必要部分，避免把全部中间式堆入正文。

1. **全局理想问题，§4.1 / B.2。** 用独立进度 \(s\) 重记号，避免原文把扩散时刻与编辑端点混用：

\[
\min_{\rho,u}\int_0^1\int \tfrac12\|u_s(x)\|^2\rho_s(x)\,dx\,ds,
\quad\partial_s\rho_s+\nabla\cdot(\rho_su_s)=0,
\quad\rho_0=p_{\rm src},\ \rho_1=p_{\rm tar}.
\]

这里 \(u\) 是**完整编辑场**；附录 B.1 D2 明确它不是加在另一个参考场上的残差。该式是理想建模目标，后续算法并不数值求解这整个密度边值问题。

2. **可查询量，§3.2 / B.1 D3。** 以下保留论文局部噪声时刻 \(t\)：

\[
R(x_\tau,t)=\mathbb E_{z\sim K_t(\cdot\mid x_\tau)}
\left[\mathcal B_t\{Q(z,t,c_{\rm tar})-Q(z,t,c_{\rm src})\}\right].
\]

\(x_\tau\) 固定为源图像锚点；\(K_t\) 是加噪核；\(Q\) 是预训练模型输出；\(\mathcal B_t\) 把不同预测参数化的输出换算到共同比较单位。源、目标条件共享带噪输入。这里是代理构造，不是已证明的理想场可观测性。

3. **桥接假设，B.1 A1–A3。** A1：\(R=u+\varepsilon\)，噪声局部零均值；A2：窗口 \([t-\delta,t]\) 内场在锚点附近近似常值，局部质量权重可吸收；A3：上一估计附近的二次先验，权重取与 \(t\) 成比例。三者是额外建模条件。

4. **实际可解子问题，§4.2 / B.3–B.4。**

\[
\Phi_t(u)=t\|u-\hat u_{t-\delta}\|^2+
\int_{t-\delta}^t\|u-R(x_\tau,\xi)\|^2d\xi,
\]

\[
u^\star_{\rm loc}=
\frac{t\hat u_{t-\delta}+\int_{t-\delta}^tR(x_\tau,\xi)d\xi}{t+\delta}.
\]

第二式是第一式的精确最小化解；不能把符号 \(u^\star_{\rm loc}\) 当成全局 OT 最优场。

5. **可计算规则，§4.2 / B.5。** 用 \(R(x_\tau,t-\delta)\) 替代上一估计，右端点求积替代积分：

\[
\hat u_t=
\frac{tR(x_\tau,t-\delta)+\delta R(x_\tau,t)}{t+\delta},
\qquad x^{\rm pred}=x_{\rm src}+\lambda\hat u_t.
\]

6. **算法边界，§4.3–4.4 / Alg.1 / K。** 在 VAE latent 上执行。两时间、两条件的查询可拼成一次 batch；这才是论文 transport 的 1 NFE 计法。可选 refinement 是额外一次目标条件原生 predict-\(x_0\) 调用，完整方案计 2 NFE。多噪声版本先平均估计，再作一次输运；不等于多步轨迹积分。不要把一次 batch 调用写成只计算一个条件、一个时间点，也不要省去默认完整方案的清理成本。

## 保证范围：我们独立整理的数学边界

这些判断是对上述公式的数学分析，不是原文主张的照录。

- 对 \(a=t/(t+\delta)\)，凸性直接保证
  \(\|aR_-+(1-a)R_+\|^2\le a\|R_-\|^2+(1-a)\|R_+\|^2\)。它没有保证结果小于当前 \(R_+\) 的能量，也没有保证语义正确或满足目标分布边界。
- 固定卷积核的无权时间积分收缩，不能不加条件地推广到随时间变化的密度权重 \(\rho_t\)。实际两点规则的权重也随 \(t\) 变；微分会多出 \(a'(t)(R_- -R_+)\)。因此固定卷积的导数收缩证明不能直接覆盖实际规则。
- 二次 surrogate 严格凸，只说明给定 surrogate 后解唯一；OT 没有唯一决定先验、误差模型和时间权重。如果使用严格 MAP 解释，零均值噪声本身也不足以推出高斯二次似然。
- 稳定性或积分误差上界的改善，不等于实际误差必然改善，更不等于精确求解全局 OT。平滑有偏差与相关噪声的权衡；共享噪声下尤其不能直接套独立噪声的降方差结论。
- 原文 §3.1 与附录 L 对 \(p_0\) 的噪声先验和目标图像端点称谓有歧义；主文件建议采用上面的独立输运进度 \(s\)。这只是清晰重记号，不能借此补成原文未证明的等价性。

既有[核查文件](../research_synthesis_20260927/CHORDEDIT_LOGIC.md)还记录了官方源码的具体 \(x_0\) 差实现与统一速度域理论写法的差别。本次用户主要需要论文思路，不必把源码差别扩展成另一条讨论主线。

## 对我们可借鉴的内容

可借鉴的是寻找“失败直接发生的计算对象”，使现象、优化未知量、可用观测和最终操作处于同一条链；不是预先指定必须使用 OT 或低能量。我们的未知反事实未来没有 ChordEdit 那样可查询的源／目标条件差。应明确寻找合法替代信息来源及桥接假设，而不能将“正确未来分布”直接放入约束。我们的动作后果坍缩还提示：抑制波动与恢复必要分化可能相冲突；最终数学对象需要解释该选择性，而不仅是总体变平滑。
