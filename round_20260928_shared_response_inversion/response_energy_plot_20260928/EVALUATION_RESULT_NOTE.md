# 封存后评估的直接结论

评分使用 `FINAL_MODEL_PREDICTIONS_SEALED.json` 与 `FINAL_SELECTED_BY_VALIDATION.json`。所有模型与原生预测散列匹配；测试真实响应文件对采集封存散列匹配，真实动作词与公开部署词表完全同序。评分后没有训练、调参或重选模型。

输出为512条root/seed/horizon记录和62,720条终点候选对记录。独立episode仅4个；同episode的两个锚点及其全部候选对均为相关测量。各训练seed单独预测评分，再平均；未使用预测ensemble。候选对仅描述，不用作置信区间样本。最终两张后果差分图和逐步曲线已实际查看，所有方法共享核心图坐标与正交误差色标，未裁掉离群点。

裸SPECTRAL相对同信息GRU：H3完整误差+2.094%、差分误差+36.542%；H5完整误差+3.047%、差分误差+51.646%。H5差分误差在四个episode均更差，完整误差则两个更好、两个更坏。四episode的描述性bootstrap不是跨任务普遍性证据。

两个值得固定的解释：

1. **本次新动作池没有复现原生预测的普遍后果塌缩。** 其终点方向增益约0.95，核心图大部分点贴近正确对角线。不能为了先前叙事，把这张图冻结成“现代世界模型普遍无法组合动作后果”的证据。旧失败案例仍然存在，但本轮没有扩展其适用范围。
2. **标准响应谱实现没有在本次数据/容量/预算下获得优势。** 与GRU的方向增益几乎相同，额外错误大量出现在正交方向，说明只画差分长度或一条投影会漏掉机制失败。谱臂某些目标regret较好不代表完整动力学恢复。

本评估不单独证明物体响应正确：全视觉编码包含推杆、自运动、物体和其他画面信息。物体运动范围、真实重构读出误差等由独立几何诊断说明，不能从上述全局数值倒推。

未解决的因果归因包括：有限34个训练根、合法初始化泛化、低维读出限制、线性闭合及训练参数化。当前结果足以否定本轮“裸谱共同状态已有额外收益”的形成假说，不能否定所有响应状态表示，也不能由弱小训练参考臂失败宣布必须发明新机制。
