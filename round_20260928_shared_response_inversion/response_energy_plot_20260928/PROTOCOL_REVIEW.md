# 冻结响应问题与公平形成实验：独立协议审查

日期：2026-09-28。范围：数学、数据与统计协议；没有调用本地 skills，没有新环境采集、训练或自行修改主代码。本协议落实用户要求的“先解决围绕的问题、冻结我们的 energy plot”，不提出新的核心算法，也不将经典谱实现晋升为创新。

## 1. 本轮真正需要回答的问题

**在相同训练响应、合法历史与合理计算预算下，用真实交叉作用响应定义一个共同递推状态，是否比直接多步辨识或普通递归学习，更准确地预测新历史上的未见动作组合及其完整后果？**

这个问题有三种不同结论：

1. 谱实现优于同模型类直接训练：首先说明某种数据组织/辨识求解优势，不自动说明状态模型类更好。
2. 两种共同线性实现都优于普通递归模型：只支持该任务和预算下的状态/模型类比较，仍须排除容量、优化不足和超参搜索不公平。
3. 同信息普通方法已解决：当前 energy plot 所展示的困难可以成立，但不能由此要求一种新机制；该版本不值得进入主论文扩大实验。

旧原生模型只作能力参照。它没有利用新增训练响应，击败它不能回答上述问题。

## 2. 最小连贯数据配置

优先使用一个固定形状、一个统一离散宏动作字典。建议 q=3 作为最小形成验证；若预算允许，q=5 覆盖空作用和二维正负方向。字典在观察新结果之前固定，所有根历史共用数值相同的宏动作，不按根历史重新定向。

建议至少 24 个训练 root、8 个验证 root、8 个测试 root。每个 root 是独立初始 episode/seed 的完整已完成前缀，不能把同 episode 的相邻锚点当独立 root。固定三帧合法历史及相应已执行动作，所有方法完全相同。旧反复查看过的四案只能保留为开发回归，不能作为这次独立测试。

训练与验证各 root 完成所有二步词。设 V={epsilon} union A：H 包含当前输出及每个一步响应，H^a 包含在 a 之后的 V 响应。每条两步记录保留一步端点，以同一实际记录构建重叠表项；检测重复一步端点的一致性。V 对删除首动作封闭。

测试使用预先固定的 H3/H5 动作词及全部中间宏步输出。建议每个测试 root 至少 12 条 H5 词，在动作空间中固定均衡设计，包含顺序不同、作用中止、相反动作和重复动作。不得依据其真实后果挑选。所有短前缀可以共享记录，但统计时仍以 root 为单元。

测试 H3/H5 的组合未参与 H、H^a 或训练目标；验证长词可以用于选择 rank/早停，但应明确报告模型选择已看过验证长时域，不能称为完全无长时域开发。若本次只用二步验证选择，结论更直接，但所有臂都必须如此。

不要称这些为连续动作泛化：字典固定，未见的是组合、长度及历史。不要用控制器隐藏状态或 query future 初始化模型。

## 3. 输出和矩阵的一致定义

固定同一 384 维视觉编码器和可见 proprio。所有数据集使用同一编码器权重/版本；输出缩放仅由训练集确定，视觉和 proprio 分块报告。不要对每个 action 或每个 horizon 独立归一化。

动态状态维度建议 r in {4,8}，总齐次维度 r+1。必须 r+1 < 训练 H 列数；报告奇异值和训练/验证误差，避免满秩小表插值伪装成状态发现。

三臂均允许仿射读出。谱臂和直接线性臂均允许仿射状态转移，可写成齐次 x=[1;s]，其中 A_a 的第一行恒为 [1,0,...,0]。附件正例的 rank=3 本来就包含一个常数坐标；不允许常数可能把均值/平移表达限制误判为动力学缺陷。

一个无需新模块的实现是：按 history 列中心化 H，做 rank-r SVD 得到 O_dyn 和 X_dyn；令 O=[mean(H),O_dyn]、X=[ones;X_dyn]。对每个 a，固定 A_a 第一行后拟合其其余各行：

    B_a = O_dyn^dagger (H^a - mean(H) ones) X^dagger
    A_a = [1 0 ... 0; B_a]

这里 mean(H) 是逐表行在训练历史上的均值；完整输出读出 C 取 epsilon 行块。若采用其他等价齐次实现，应记录常数保持误差。一般谱正则/截断属于经典辨识，不应添加创新命名。

最终评价必须使用实际递推 C A_last ... A_first x，不得用表中直接读出代替。额外报告 O_v 与 C A(v) 在已知短词上的偏差，避免静态响应表拟合与部署语义分离。

## 4. 合法初始化：选择一个简单共同入口

**推荐统一的历史编码器架构，三臂分别训练其参数。** 例如拼接三帧视觉 token、可见 proprio 和已完成动作后，用小型 MLP 或固定线性头得到 s。历史头架构、输入、搜索范围均一致。谱臂以仅来自训练响应表的状态坐标作为监督拟合历史头；其余两臂从同一训练分支的前向输出误差学习历史头。

这允许谱臂使用未来训练标签塑造状态，属于监督训练；测试只能读过去。由于其他方法已获得同一完整训练响应，这不构成额外数据。但是坐标监督与端到端优化不同，正是需要记录的辨识差别。

不建议这次使用过去窗口的岭 observer：事实历史动作通常不在离散字典内，为了初始化再引入连续 A(a) 或逆动作拟合，会添加本次尚未验证的建模假设。也不建议让直接臂固定使用已经拟合好的谱历史头，那会不对称地强迫它继承谱坐标。

有限训练 root 对高维历史头有明显过拟合风险。MLP 应很小并有独立验证；线性 ridge 历史头可以作为整个实验统一选择，但不可只给谱臂更强初始化。应分别报告：训练真 X 初始化的 oracle 诊断、训练合法历史头、测试合法历史头。oracle 臂只诊断初始化瓶颈，不能当部署收益。

## 5. 三个主体臂

| 臂 | 状态与动作更新 | 训练信息和目标 |
|---|---|---|
| Spectral | 同一 r 维动态状态，离散仿射 A_a，线性/仿射 C | H/H^a 谱辨识及历史头监督；只用训练的实际二步响应 |
| Direct-linear | 相同历史头、r、离散仿射 A_a、C | 同一全部分支的当前/一步/两步完整输出误差，端到端优化 |
| Standard-RNN | 同样历史输入、r、仿射 C；普通 tanh RNN/GRU 动作条件更新 | 同一全部分支、相同输出目标，端到端优化 |

普通 RNN 的 r 相同不代表参数量相同：记录参数量，给合理优化预算。最小对照先选择普通 tanh RNN；如果失败，不能把容量更弱的 r 维 RNN 当所有非线性方法失败。预算允许时宽度增加到接近参数量只作为容量敏感性诊断，不能悄悄只给某一臂调参。

至少 3 个训练初始化 seed，用验证集确定早停或收敛。谱算法本身确定性，历史头仍有初始化误差。端到端臂必须确认训练损失合理收敛；一次优化失败不能成为机制证据。总训练响应数、唯一编码样本、训练步数、优化搜索次数及耗时均记录。

不追加候选排序头、物理状态辅助头、接触模块、残差适配器或新损失串联。物体位置读出只作既有评估仪器，不能反馈训练并额外帮助某一方法。

## 6. 冻结 energy plot：一个现象、两个不能互相替代的量

建议主图名为“动作后果的分化与准确性”，energy plot 是研究作用的类比，不宣称存在物理能量。

对同一 root、同一 horizon、两条候选 U,V，令：

    delta = y_true(U) - y_true(V)
    delta_hat = y_pred(U) - y_pred(V)
    d = norm(delta)
    aligned = dot(delta_hat, delta) / d       (d > 0)
    orthogonal = norm(delta_hat - aligned * delta / d)

主散点横轴 d，纵轴 aligned；理想位置是 y=x，分支塌缩靠近 y=0，方向反转在 y<0。颜色表达 orthogonal，避免错误方向的大幅分化被当作成功。d=0 的点不计算方向投影，单独保留零差异组的 norm(delta_hat)；不能删掉这类无作用例子。

该图必须伴随两个数字/曲线：完整视觉输出 MSE 与向量差分 MSE，分别按 H1..H5 报告。共同偏移可以让差分完美而所有后果错误；分支幅度正确也可能方向错误。proprio、自运动和物体读出分别报告，候选代价差/选择后置，不让 regret 掩盖动力学恶化。

若需要简化可视化，主图画每个 root 对固定候选对的点，其他候选对放完整数据表；不按结果挑选最好 pair。基准、谱、直接和 RNN 四个面板坐标共用，不能各自缩放。

图冻结的是可检验现象和评价对象，不冻结一个必然成立的缺陷诊断，更不冻结后续必须使用谱实现。若新增强基线已消除塌缩，应如实改变图中的比较结论。

## 7. 统计与裁定

以 root 为独立评价单元。先在每个 root 内平均预先固定候选和候选对，再比较方法。不能把 O(K^2) 个 pair 当成独立样本获得极小 p 值。3 个训练 seed 表达优化方差，不是 3 套独立采集环境。

建议报告每个 root 的配对差值、跨 root 均值/中位数、全部训练 seed；8 个测试 root 只是形成验证，bootstrap 区间仅描述有限 root 不确定性，不宣称稳健全域规律。

预先裁定顺序：

1. 数据与重复性、训练信息、递推语义门通过；否则不比较机制。
2. 普通方法训练充分；否则归类优化未解决，不判谱状态优势。
3. 必须同时检查完整后果与分支差分：一好一坏意味着 tradeoff，不能宣布恢复动作后果。
4. 谱臂只有表拟合好而合法初始化差：形成实验未完成，不把 oracle 成绩提升为方法成果。
5. 三臂都差：先区分训练覆盖/有限秩/短时域/初始化，不立即宣称发现新的 JEPA 结构性缺陷。
6. 两个公平基线已解决：把当前候选降为已知方法可处理的现象；不靠追加模块救主机制。

## 8. 最小配置结论与边界

最连贯路径是：统一真实训练分支 → 一个共同合法历史入口 → 三种普通辨识/递推方式 → 完整后果和分支差分的联合评价。此时每一组件都已有明确公平性功能，没有并列创新模块。

q=3、24/8/8 roots、r={4,8}、每训练 root 全部二步词、测试每 root 12 个 H5 词、三训练 seeds，是能较快形成判断的模板，不是保证统计充分的论文配置。若时间/算力只允许更小版本，报告必须降格为 smoke test，不能把它写成“围绕的问题已解决”。最终以实际完整执行、未泄漏和收敛情况裁定。

本轮原型能够回答“这套经典状态构造是否值得继续借鉴、问题是否被普通方法消除”；它本身不建立 novelty，也不预先选择我们的关键求解原则。

## 9. 与本轮已冻结实现的对接（优先于上面的建议模板）

主执行者冻结的配置为：T/L 的 samples 2..7 作训练（mpc2/3/4，显式 manifest 约34 roots、12 episodes），samples8..9 作验证（mpc2/4，8 roots、4 episodes），samples10..11 作测试（mpc2/4，8 roots、4 episodes）。这些旧事实 episode 不是从未查看过的新场景，因此本轮是开发形成比较；新采集的是交叉未来响应。

q=5，统一零宏动作与二维正负0.12动作；每宏动作含五个相同微步控制。训练、验证、测试都采全25个二步词；测试另外20个 H5 词，其 H3 是实际前三步。测试二步记录不得流入训练、坐标求解、初始化或调参。验证仅用 H2 选参，不看测试 H3/H5。主输出是视觉384维，proprio仅作合法历史输入，不混进主读出损失。r={4,8}、三训练 seeds；GRU另允许更大容量作为强对照。

**统计独立单元因此是测试4 episodes，不是8 roots。** 先在同episode的两个锚点内聚合，然后配对报告。四个episode只足够给形成证据，不适合强显著性或总体泛化结论。

实现拟使用白化状态：

    mu = mean(H, axis=1, keepdims=True)
    U, singular, Vt = svd(H - mu)
    O = U[:, :r] * (singular[:r] / sqrt(N))[None, :]
    X = sqrt(N) * Vt[:r, :]
    Xaug = vstack([ones((1, N)), X])
    B_a = pinv(O) @ (H_a - mu) @ pinv(Xaug)
    A_a = vstack([[1, 0, ..., 0], B_a])
    C = hstack([mu[:384], O[:384]])

上述算法的 H 和 H_a 均按训练统一输出缩放形成；mu的广播应为列向量。该写法成立，并保证训练状态的总体协方差为单位阵（非零截断奇异值条件下）。不需要额外引入训练阶段物理变量。

**history MLP最终层必须为线性输出。** 隐藏层可以tanh，但白化X必然可能超过[-1,1]，不能把最终s限制在tanh范围。独立合成复核中36.03%的白化坐标超过该范围，最大绝对值2.406；最终tanh会人为制造谱初始化失败。

独立代码 `check_affine_spectral.py` 已复核上述白化、仿射移位、误差正交分解和H5递推。H重构最大误差1.24e-14，移位最大误差7.99e-15，100条H5合成动作词最大误差1.82e-14，常数坐标误差0。这只是代数/实现验证，不能当真实视觉收益。结果保存在 `AFFINE_SPECTRAL_CHECKS.json`。

1500步固定优化预算可以先执行，但必须读取训练/验证曲线。若普通臂尚未收敛，只能记作当前预算下结果，不能裁定谱求解具有结构性优势。条件性的same-state非线性诊断保留固定谱读出，测试的是该坐标/读出下线性更新是否受限；它不检验所有可能状态，也不是额外论文模块。
