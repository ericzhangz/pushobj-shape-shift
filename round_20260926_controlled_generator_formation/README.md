# 2026-09-26：共同作用形成参照

本目录单独发布本轮实验，不改写 Round 2–5。它检验标准共同作用场载体能否保持冻结 F0 的粗边界预测，以及只用前半已完成经历修订后能否迁移到真实后半。它不是 Log-ODE 原创机制、未训练混合响应成功或闭环规划收益的报告。

## 两个主要入口

- [实验结果](results/README.md)：逐例 CSV、门结果、运行合同、保存权重与 teacher 查询。
- [实验分析](reports/REPORT.md)：替换、适配和数值误差分账，以及本轮停止裁定。

## 分区

| 目录 | 内容 |
| --- | --- |
| `reports/` | 执行前合同、完整分析、审查背景及冻结研究问题摘要 |
| `results/formation_run/` | 全 D 输入、无 D 标签更新的 F0 粗边界 lift；4/4 过门 |
| `results/prefix_formation_run/` | 独立前半 lift、V0/VD 封存和后半留出；D 门 0/4 |
| `results/post_seal_attribution/` | 同输入替换差与同字段 RK2 细化；零训练 |
| `code/` | 本轮实现及其运行/测试依赖的源码快照，不替换仓库旧版本 |
| `logs/` | 三次实际执行日志的公开脱敏副本 |

支持平均 RMS 从 0.09103 降至 0.02226，但留后仍未胜原生 F0；退化在未适配学生替换阶段已出现。门失败不等于 D 完全没有迁移，更不否定所有共享生成元。未增加环境分支、未读取新候选真值、未调整通过门。

36 个 CPU 回归测试通过；CSV/JSON/PT 保留实际结果。原生 checkpoint、DINO cache、此前完整 donor/RGB 证据和私人审查附件不在此次上传范围，因此本目录不是一键端到端复现包。完整条件及实际运行步骤见 [代码说明](code/README.md) 和 [发布清单](PUBLISH_MANIFEST.md)。
