# 审查背景摘要

用户为本轮提供了两份针对早前有限任务泛函推导的审查。本页只保留影响实验设计的要点，不发布私人附件、不保留附件 ID 或本机用户目录，也不将其当作新的实验真值。

两份审查认可：固定动作链、固定模型和编码器、原生历史语义及同一评价规则下，逐步真实前缀替换的望远镜、有限缺陷积分表示和有限候选选择界可成立。认可的定位是已发生误差的解释与分析，而不是新动作的误差预测机制。

对后续实验的约束是：

1. 新动作缺陷及其真实前缀未知；不能将它们用于在线拟合后再称为迁移。
2. 已完成链的任务误差和局部作用可以从端点评分取得，积分不增加真实信息。
3. 若使用估计缺陷，积分与端点差应使用同一估计输入，区分数值误差、缺陷迁移和条件上下文误差。
4. 低支持损失、小代数/积分误差不等于更好的动作排序；标量符号不等于动作梯度或候选排序已正确。
5. 旧 B 候选池属于开发材料；整计划 B、指定续行 C 和原生反馈 MPC 的对象不同。
6. 比较共享预测修订时保留同信息普通 factual、任务感知和直接标量参照；不存在的历史 H5 标签不能凭空制造。

本轮据此不重复精化旧积分，先检验共同作用形成载体。由于形成门未过，未进入候选任务对比；因此没有以接口预检代替上述强参照和任务验证。
