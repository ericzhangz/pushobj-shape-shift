# Prior-stage boundary

前一阶段做过两类诊断：

1. 用查询前历史缺陷构造 `TASK_FINITE_NEAREST/MEAN` 迁移，比较模型前缀、真实前缀和真实候选缺陷；它定位了简单历史缺陷替代的失准，但不是 AdaJEPA 参数更新的根因。
2. 用事实链上的有限端点/中点积分检查任务误差的逐步代价增量；它区分了积分数值误差与未来缺陷/上下文误差，但中点使用真实下一帧，不能作为新动作校正器。

这些材料对应仓库前几轮的分析分区。本轮只保留它们的解释边界，不复制旧的完整结果表，也不把它们合并到 B1 归因的主结论中。当前主问题仍是：查询前经历能否预测新候选之间的任务误差差 `ΔE`。
